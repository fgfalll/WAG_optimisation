Перенесення маси, імпульсу та енергії у порово-тріщинуватих геологічних середовищах описується жорстко зв'язаними системами нелінійних диференціальних рівнянь у приватних похідних. У таких обчислювальних середовищах примітивні unit-тести виявляються повністю неспроможними гарантувати фізичну правдоподібність та чисельну стійкість.

Безпекова парадигма Rust надає унікальні мовні інструменти — нульову вартість абстракцій (zero-cost abstractions), гарантії безпеки роботи з пам'яттю на етапі компіляції та суворе управління часом життя посилань (lifetimes) для масштабних розріджених матриць. 1.1 Обмеженість стандартного метричного покриття (Code Coverage) у чисельному моделюванні

У традиційній інженерії програмного забезпечення досягнення високих показників тестового покриття коду (Line або Branch Coverage на рівні 95–100%) вважається еталоном надійності. Проте у чисельному моделюванні фільтраційних процесів високий відсоток покриття коду є хибним критерієм надійності і створює ілюзію коректності.

Код обчислювального ядра на Rust, що має 100% Code Coverage і виконується без панік (panic!), може генерувати катастрофічні помилки розрахунку, зумовлені відсутністю справжнього 3D скінченно-об'ємного (FVM) масового балансу та використанні незв'язаних сурогатних формулювань:

1. Чисельна дисипація та розмиття фронтів: Схема дискретизації може надмірно згладжувати круті фронти насиченості, перетворюючи поршневе витіснення на розмиту нефізичну зону.
2. Немонотонні осциляції та генерація фальшивих мод: Некоректно підібрані апвінд-схеми або порушення TVD-властивостей провокують фальшиві хвилі тиску та насиченості у районі штучних розривів.
3. Пастка штучних штрафних бар'єрів (Breakthrough Penalty Trap): Застосування евристичних множників витиснення (наприклад, жорсткого множення результату на штраф result *= breakthrough_impact або штучного падіння NPV на -1.0 \times 10^{12}) заганяє оптимізаційні алгоритми на нижні межі пошуку (наприклад, затискання дебіту на 5,000 MSCFD замість діапазону 20,000–60,000 MSCFD).
4. Фантомний видобуток флюїду та викривлення утилізації CO_2: Розз'єднання оцінки коефіцієнта вилучення (RF) від динамічного пластового тиску \bar{P}_{\text{res,eff}} або відсутність суворого зв'язку з прокачаним об'ємом порок у порових об'ємах (HCPVI) призводить до розрахунку фантомної утилізації CO_2 (< 1 MSCF/STB замість нормативних 5-10 MSCF/STB чи 0.25-0.50 т/STB).

Двома яскравими прикладами протиставлення спрощених сурогатів повноцінній 3D FVM дискретизації є динамічне порівняння за фракційним потоком Ковала та накопиченим витісненням:

f_g(t) = \frac{1}{1 + \left(\frac{1 - S_w(t) - S_g(t)}{S_g(t) - S_{gc}}\right) \cdot \frac{\mu_g}{\mu_o}}

RF(t) \le RF_{\text{ult}} \cdot \left(1 - e^{-\frac{\text{HCPVI}}{\tau}}\right)

Якщо чисельне ядро не реалізує чесний покомпонентний баланс мас FVM на 3D сітці, а спирається на незв'язані аналітичні наближення, воно не здатне відтворити реальний прорив газу при високих коефіцієнтах рухливості \frac{\mu_g}{\mu_o}, що призводить до колапсу оптимізатора.

1.2 Двокомпонентний принцип V&V: Verification vs Validation

Забезпечення надійності чисельного ядра на Rust базується на принциповому розмежуванні двох методологічних дисциплін:

                          +-------------------------+
                          |   Розробка THMC-ядра    |
                          +-------------------------+
                                       |
                   +-------------------+-------------------+
                   |                                       |
                   v                                       v
     +---------------------------+           +---------------------------+
     |       VERIFICATION        |           |        VALIDATION         |
     |   "Чи правильно ми        |           |   "Чи правильні рівняння   |
     |   розв'язуємо рівняння?"  |           |   ми розв'язуємо?"        |
     +---------------------------+           +---------------------------+
     | * Перевірка аппроксимації |           | * Відповідність фізиці    |
     | * Порядок збіжності O(dt) |           | * Відсутність фантомного  |
     | * Збереження маси <10^-12 |           |   видобутку / утилізації  |
     | * M-matrix та монотонність|           | * SPE benchmarks (1..11)  |
     +---------------------------+           +---------------------------+

* Верифікація (Verification) відповідає на запитання: «Чи правильно ми розв'язуємо обрані математичні рівняння?» Вона контролює математичну точність чисельної дискретизації, дотримання заявленого порядку часової та просторової збіжності, збереження алгебраїчних інваріантів, відсутність помилок операторного розщеплення та чисельну стійкість матричних розв'язувачів.
* Валідація (Validation) відповідає на запитання: «Чи правильні рівняння ми розв'язуємо для опису реального пласта?» Вона перевіряє відповідність чисельних результатів справжнім фізичним процесам фільтрації, геомеханіки та фазової рівноваги, порівнюючи розрахунки з лабораторними випробуваннями кернів, аналітичними розв'язками та польовими даними розробки.

Для гарантування цілісності розрахунків чисельне ядро повинно задовольняти фундаментальні фізичні інваріанти: покомпонентне збереження маси, обмеженість змінних стану, термодинамічну монотонність мінімізації вільної енергії Гіббса та симетрію просторових дискретних операторів.

Для автоматизованої перевірки цих фундаментальних вимог чисельне ядро послідовно пропускається через перший рівень V&V системи — аналітичні бенчмарки з точним математичним розв'язком.

1. Рівень 1 — Аналітичні бенчмарки та канонічні розв'язки (Analytical Benchmarks)

Перший рівень V&V комплексу призначений для ізоляції та локалізації помилок аппроксимації, просторової та часової дискретизації шляхом порівняння обчислених полів із точними замкненими аналітичними розв'язками.

2.1 1D Двофазне витіснення Баклі-Леверета (Buckley-Leverett Test)

Тест Баклі-Леверета є фундаментальним аналітичним стандартом верифікації двофазного незмішуваного витіснення нафти газом чи водою у одновимірному пласті без урахування капілярного тиску.

* Постановка тесту: Інжекція витісняючої фази зі сталою швидкістю в однорідний 1D пласт із початковою насиченістю зв'язаної води S_{wi}.
* Математичний контроль: Чисельне ядро Rust зобов'язане точно відтворювати позицію та швидкість стрибка насиченості (ударного фронту), які розраховуються за аналітичним методом Вельге (Welge construction) через дотичну до функції дробового потоку:

f_g(S_g) = \frac{1}{1 + \frac{k_{ro}(S_g)}{k_{rg}(S_g)} \cdot \frac{\mu_g}{\mu_o}}

* Вимоги до чисельної схеми у Rust: Застосування високоефективної TVD/WENO5 схеми у Rust-модулі має забезпечити високу роздільну здатність ударного фронту без штучного розмиття (сіткової дисперсії) та без виникнення нефізичних осциляцій (перельотів/недольотів насиченості) поза межами [S_{wi}, 1 - S_{or}].

2.2 Задачі консолідації поропружності Терцагі та Манделя (Terzaghi & Mandel Consolidation)

Для верифікації геомеханічного сателіта та його закритичного зв'язку з фільтраційним потоком використовуються класичні задачі поропружності.

|              |||||          |        |             ||||||||            |
|       +---------------+     |        |       +-----------------+       |
|       | Поровий тиск  |     |        |       | Дреновані боки  |       |

1. 1D Стиск Терцагі: Моделюється одновимірна консолідація водонасиченого породного шару під дією постійного зовнішнього механічного навантаження з одностороннім дренажем. Чисельний розв'язок повинен демонструвати точне співпадання часової дисипації порового тиску та осідання з експоненційним аналітичним рядом Фур'є.
2. 2D/3D Задача Манделя: Прямокутний зразок піддається миттєвому стисненню між двома жорсткими непроникними плитами з можливістю вільного дренажу флюїду через бічні межі.
3. Ефект Манделя-Крайєра (Mandel-Cryer effect): На початкових часових інтервалах чисельне ядро зобов'язане відтворювати фізичний ефект — тимчасове зростання порового тиску у центрі зразка вище початкового рівня за рахунок передачі напружень від зневоднених периферійних зон.
4. Запобігання Pressure Locking та Inf-Sup Стійкість: Застосування стандартних скінченних елементів однакового порядку (P_1-P_1) призводить до порушення дискретної умови стійкості Ледиженської-Бабушки-Бреззі (Inf-Sup / LBB condition), що викликає фальшиві просторові осциляції тиску в умовах низької проникності або ненадранованого стиску. Схема скінченних елементів на Rust обов'язково використовує змішані елементні пари Тейлора-Худа (P_2-P_1, де вектор переміщень апроксимується квадратичними поліномами P_2, а тиск — лінійними P_1).

2.3 Аналітичні профілі розкриття тріщин ГРП Снеддона та KGD (Sneddon & KGD Fracture Profiles)

Верифікація геомеханічного ядра при моделюванні гідравлічного розриву пласта (ГРП) спирається на аналітичні розв'язки теорії тріщин.

* Профіль Снеддона: Для 3D дископодібної (плоскої) тріщини під дією рівномірного внутрішнього тиску флюїду P_{\text{net}} профіль розкриття w_f(x) описується аналітичною залежністю:

w_f(x) \propto \sqrt{1 - \left(\frac{x}{L}\right)^2}

де L — напівдовжина тріщини, x — координата від центру.

* Профіль KGD (Kristianovich-Geertsma-de Klerk): Моделюється плоска деформація тріщини кінцевої висоти при інжекції в'язкого флюїду. Допуск відхилення розрахованого геомеханічним сателітом розкриття тріщини та напружено-деформованого стану поблизу вершини тріщини від аналітичного розв'язку не повинен перевищувати 0.5\%.

2.4 Неізотермічний теплоперенос Авдоніна (Avdonin Non-Isothermal Solution)

Для верифікації температурного блоку (T-компонента THMC моделі) використовується розв'язок Авдоніна для інжекції холодної рідини у гарячий пласт. Розв'язок враховує не лише конвективний перенос тепла флюїдом усередині пласта, але й кондуктивний теплообмін через непроникні покрівлю та підошву пласта. Чисельна схема має демонструвати відсутність осциляцій на температурному фронті та точний баланс теплової енергії.

Рівень 2 забезпечує жорсткий аудит виконання фундаментальних фізичних законів збереження безпосередньо на рівні дискретних рівнянь. Нехтування строгими алгебраїчними інваріантами призводить до швидкого накопичення похибок при розрахунку тривалих періодів розробки.

3.1 Покомпонентний масовий баланс із машинною точністю

Для кожного з N_c фільтруючих компонентів у чисельному ядрі на Rust виконується автоматичний перевірочний контроль масового балансу на кожному часовому кроці \Delta t.

* Математичний критерій розв'язувача:

\left| \sum_{k} M_i^{(k)}(t) + \int_0^t Q_{\text{prod},i}(\tau) d\tau - \int_0^t Q_{\text{inj},i}(\tau) d\tau - \sum_{k} M_i^{(k)}(0) \right| < 10^{-12}

де M_i^{(k)}(t) — накопичена маса i-го компонента у k-ій комірці розрахункової сітки у момент часу t, Q_{\text{inj},i} та Q_{\text{prod},i} — масові швидкості нагнітання та видобутку.

                             МАСОВИЙ БАЛАНС (Критерій < 10^-12)
   +---------------------------------------------------------------------------------+

   |  [Маса в пласті M(t)] + [Накопичений видобуток Q_prod] - [Накопичене нагнітання Q_inj]  |
   |  -----------------------------------------------------------------------------  |
   |                                [Початкова маса M(0)]                            |
   +---------------------------------------------------------------------------------+

                                              |
                   +--------------------------+--------------------------+
                   |                                                     |
                   v                                                     v
         ПОМИЛКА БАЛАНСУ < 10^-12                              ПОМИЛКА БАЛАНСУ > 10^-12
     +-------------------------------+                     +-------------------------------+
     |  * Фізично коректні профілі   |                     |  * Фантомні об'єми нафти/газу |
     |  * Точна утилізація CO2       |                     |  * Помилкові розрахунки NPV   |
     |  * Стійкість розв'язувача     |                     |  * Розбіжність Ньютона-Рафсона|
     +-------------------------------+                     +-------------------------------+

* Чітке розмежування допусків (Disambiguation):
  * Для повного 3D FVM нелінійного розв'язувача (Newton-Raphson + Krylov solver) значення 10^{-12} є безапеляційним математичним критерієм збіжності на кожному кроці за часом.
  * Поріг \ge 99.9\% (10^{-3}) стосується виключно спрощених/грубих сурогатних діагностичних моделей верхнього рівня, але категорично неприпустимий усередині основного чисельного ядра.

Недотримання машинного порогу 10^{-12} призводить до генерації фантомних об'ємів флюїду та викривлення показників утилізації CO_2 (< 1 MSCF/STB замість проектних 5-10 MSCF/STB), що руйнує фінансові розрахунки чистої дисконтованої вартості (NPV).

3.2 Інваріант додатності насиченостей та замикання складів

Змінні стану пластово-флюїдної системи повинні задовольняти суворі фізичні границі на кожній ітерації нелінійного розв'язувача Ньютона-Рафсона:

1. Границі фазових насиченостей: S_\alpha \in [0, 1] для кожної фази \alpha \in \{o, w, g\}.
2. Умова замикання мольних часток: \sum_{i=1}^{N_c} z_i = 1.0 та \sum_{\alpha} S_\alpha = 1.0.
3. Категорична заборона Clamping: Категорично забороняється використання штучних процедур затискання (clamping від'ємних насиченостей до 0.0 або значень >1.0 до 1.0) після розв'язання СЛАР. Затискання порушує консервативність дискретної схеми. Інваріант належності інтервалу [0, 1] гарантується безпосередньо формулюванням дискретної схеми та точним розрахунком матриці Якобі.

Типобезпечна архітектура Rust гарантує ці інваріанти на етапі компіляції завдяки сильному типуванню фізичних одиниць:

# [derive(Debug, Clone, Copy, PartialEq)]
pub struct Pascal(pub f64);

# [derive(Debug, Clone, Copy, PartialEq)]
pub struct MoleFraction(pub f64);

impl MoleFraction {
    pub fn new(val: f64) -> Result<Self, NumericalDivergenceError> {
        if (0.0..=1.0).contains(&val) {
            Ok(MoleFraction(val))
        } else {
            Err(NumericalDivergenceError::UnphysicalMoleFraction(val))
        }
    }
}

3.3 Симетрія, додатна визначеність та M-matrix властивості оператора MPFA-O

Обчислення дифузійних та фільтраційних потоків на складних косокутних сітках з геологічними зсувами (Corner-Point grids) виконується за допомогою методу багатоточкової апроксимації тиску (Multi-Point Flux Approximation — MPFA-O).

* Перевірка M-matrix властивостей: Дискретний оператор фільтрації повинен формувати матрицю, що задовольняє властивості M-матриці (невід'ємні діагональні елементи, недодатні позадіагональні елементи, переважання діагоналі).
* Практичний аудит: Аудит ядра на Rust контролює додатну визначеність та симетрію оператора дифузії. Порушення M-matrix властивості викликає появу нефізичних від'ємних тисків у комірках поблизу свердловин та фальшивих зворотних потоків флюїду проти градієнта тиску.

Після перевірки дискретних інваріантів перенесення маси та імпульсу ядро піддається перевірці термодинамічної узгодженості фазових переходів.

1. Рівень 3 — Термодинамічна стабільність та монотонність Flash (EOS Flash Monotonicity)

Рівень 3 перевіряє алгоритми розщеплення фаз (Flash calculation) та рівноваги парової та рідкої фаз (VLE) на основі кубічних рівнянь стану (Equations of State — EOS) Пенга-Робінсона (PR) та Соаве-Редліха-Квонга (SRK).

4.1 Монотонність мінімізації вільної енергії Гіббса

Термодинамічна рівновага багатокомпонентної суміші при заданих тиску P, температурі T та сумарному складі z відповідає глобальному мінімуму вільної енергії Гіббса G.

* Математична вимога: Послідовність ітерацій алгоритму Flash-розрахунку повинна монотонно зменшувати функцію вільної енергії Гіббса:

G^{(k+1)}(x, y) < G^{(k)}(x, y)

де x та y — склади рідкої та газової фаз відповідно.

              МІНІМІЗАЦІЯ ЕНЕРГІЇ ГІББСА (G^(k+1) < G^(k))
    G (Енергія)
     ^
     |  * Ітерація 0 (Однофазний стан z)
     |   \
     |    \  * Ітерація 1
     |     \
     |      +----------> * Глобальний мінімум G(x, y)
     |                   (Двофазна рівновага L + V)
     +--------------------------------------------------> Ітерації

Якщо алгоритм розщеплення фаз потрапляє у локальний мінімум або демонструє немонотонні осциляції G, нелінійний розв'язувач зациклюється, а коефіцієнти фугітивності \phi_i^L та \phi_i^V втрачають фізичний зміст, викликаючи розбіжність ітерацій Ньютона-Рафсона.

4.2 Мульти-початковий тест стабільності Міхельсена (Michelsen TPD Test)

Для автоматизованої перевірки надійності термодинамічного блоку в Rust реалізовано стрес-тест аналізу функції відстані до дотичної площини (Tangent Plane Distance — TPD) Міхельсена.

* Математичне формулювання TPD:

TPD(y) = \sum_{i=1}^{N_c} y_i \left( \ln y_i + \ln \phi_i(y) - \ln z_i - \ln \phi_i(z) \right)

// Нульове виділення пам'яті у внутрішньому циклі SIMD Flash
pub fn evaluate_tpd_simd(
    z: &[f64],
    y_trial: &[f64],
    p: Pascal,
    t: Kelvin
) -> f64 {
    // Векторизоване обчислення коефіцієнтів фугітивності через std::simd (AVX-512)
    // Повертає значення TPD без динамічного виділення пам'яті у купі (zero allocations)
    let mut tpd = 0.0;
    for i in 0..z.len() {
        tpd += y_trial[i] * (y_trial[i].ln() + fugacity_coeff_gas(y_trial, p, t, i).ln()
               - z[i].ln() - fugacity_coeff_mixture(z, p, t, i).ln());
    }
    tpd
}

* Стратегія пошуку та умова стаціонарності:
  1. Тестування виконується у 10 000 випадково згенерованих точках P-T-z простору.
  2. Для кожної точки реалізується пошук стаціонарних точок шляхом розв'язання рівняння градієнта:

\nabla TPD(y) = 0

1. Генерація випробувальних складів (trial seeds) запускається з декількох початкових наближень: векторів оцінок K-факторів Уїлсона (K_i = \frac{P_{ci}}{P} \exp\left(5.37(1+\omega_i)(1 - T_{ci}/T)\right)), чистих компонентних векторів e_i та їх сумішей.
2. Якщо TPD(y) < 0 хоча б в одній стаціонарній точці, однофазний стан є нестабільним, і суміш повинна розщепитися. Це запобігає пропуску тіньових двофазних зон біля точок ретроградної конденсації.

4.3 Прикритичний безгістерезисний скан та неперервність фазових функцій

В областях станцій поблизу критичної точки властивості рідкої та газової фаз стають майже ідентичними.

* Алгоритм сканування: Виконується безгістерезисний прохід тиску та температури через критичну точку туди й назад (P \to P_c, T \to T_c).
* Критерії успіху:
  1. Співвідношення коефіцієнтів фугітивності прямують до одиниці: \frac{\phi_i^L}{\phi_i^V} \to 1.0.
  2. Всі фазові функції (густина, в'язкість, стисливість) залишаються монотонними та C^1-неперервними.
  3. У коді на Rust категорично виключається виникнення критичних помилок чисельного переповнення або невизначеностей типу NaN чи Inf.

Забезпечивши термодинамічну точність локальних фазових переходів, V&V система переходить до верифікації часової інтеграції та схем розщеплення операторів.

1. Рівень 4 — Порядок збіжності та операторне розщеплення (Temporal Convergence & Operator Splitting)

Рівень 4 верифікує точність часової дискретизації та стійкість зв'язку між окремими фізичними блоками THMC ядра.

5.1 Перевірка чисельного порядку часової збіжності

Оцінка чисельного порядку збіжності за часом здійснюється за допомогою методології систематичного подрібнення часового кроку (Grid/Time Refinement Study).

                      ЛОГАРИФМІЧНИЙ ГРАФІК ПОХИБКИ
    log(||Error||)
     ^
     |  *
     |   \  Схема Backward Euler (Нахил = 1.0)
     |    \  Порядок O(dt)
     |     *
     |
     |  *
     |   \
     |    \  Схема Radau IIA / Crank-Nicolson (Нахил = 2.0)
     |     \  Порядок O(dt^2)
     |      *
     +----------------------------------------------------> log(dt)

* Методологія: Обчислюється норма похибки розв'язку \|E(\Delta t)\| = \|u_{\text{num}} - u_{\text{exact}}\| для послідовності зменшуваних кроків \Delta t, \frac{\Delta t}{2}, \frac{\Delta t}{4}, \frac{\Delta t}{8}.
* Норматив підтвердження:
  * Для неявної схеми першого порядку (Backward Euler) логарифмічний нахил графіку похибки \alpha = \frac{\log \|E(\Delta t_1)\| - \log \|E(\Delta t_2)\|}{\log \Delta t_1 - \log \Delta t_2} повинен відповідати \alpha \approx 1.0, підтверджуючи порядок O(\Delta t).
  * Для схем вищого порядку (Crank-Nicolson або Radau IIA) нахил повинен відповідати \alpha \approx 2.0, гарантуючи порядок O(\Delta t^2).

5.2 Стабільність та швидкість збіжності Fixed-Stress Split

Зв'язок між фільтраційним блоком та геомеханічним сателітом виконується за схемою операторного розщеплення Fixed-Stress Split (почергове розв'язання фільтрації та геомеханіки на кожному часовому кроці).

* Формула стабілізаційного параметра: Для забезпечення безумовної стабільності та запобігання фальшивим осциляціям тиску до діагоналі фільтраційної матриці додається стабілізаційний параметр S_{\text{stab}}:

S_{\text{stab}} = \frac{\alpha_B^2}{K_{\text{dry}}}

де \alpha_B — коефіцієнт Біоте, K_{\text{dry}} — модуль об'ємного стиску сухого каркасу породи.

* Норматив збіжності: Послідовна staggered-схема повинна досягати повної збіжності за нормою переміщень та тиску за N_{\text{iter}} \le 3-5 субітерацій на кожному часовому кроці.

5.3 Точність ремаппінгу Streamlines \leftrightarrow FVM та відсутність Grid Orientation Effect

Для високошвидкісних лінійних моделей (Streamline simulation) перенос даних між сіткою ліній току та скінченно-об'ємною сіткою (FVM) є критичним джерелом похибок.

1. Точність ремаппінгу: Інтерполяція та ремаппінг мас компонентів між сітками зобов'язані зберігати точну сумарну масу з точністю до 10^{-14}.
2. Аудит Grid Orientation Effect: Випробування на симетричних п'ятиточкових елементах розробки (5-spot pattern) контролюють відсутність анізотропії орієнтації сітки. Результати розрахунку прориву флюїду не повинні змінюватися при повороті розрахункової сітки на 45^\circ.

Після успішного проходження локальних та часових тестів чисельне ядро піддається валідації на міжнародних стандартизованих бенчмарках SPE.

1. Рівень 5 — Промислові стандарти та міжнародні бенчмарки SPE (SPE Benchmark Suite)

П'ятий рівень реалізує валідацію симулятора на загальновизнаних міжнародних тестах Society of Petroleum Engineers (SPE), що є передумовою промислової експлуатації розробки.

6.2 Великомасштабний апскейлінг: SPE 10 (1.1 млн комірок)

Модель SPE 10 є стандартом випробування масштабної ефективності чисельних ядер на високоелементних гетерогенних сітках.

* Характеристики моделі: 1.1 \times 10^6 комірок, контрастність проникності до 6 порядків між пропластками.
* Вимоги до ядра на Rust:
  1. Паралельне формування Якобіана без блокувань (lock-free) з використанням бібліотеки rayon.
  2. Лінійна масштабованість розв'язувачів СЛАР (faer / nalgebra або PETSc-bindings) при масштабуванні на 64+ ядер.

  4. Точне збереження глобальних дебітів та маси компонентів при масштабному апскейлінгу петрофізичних властивостей.

Бенчмарк SPE 11 призначений для оцінки процесів тривалого захоплення та зберігання вуглекислого газу (CO_2 Sequestration).

  1. Розчинення CO_2 у пластовій воді з зміною густини та в'язкості.
  2. Оцінка фазового стану CO_2 (надкритичний, рідкий, газоподібний).
  3. Геомеханічний аналій цілісності покривних порід (caprock integrity) під дією зростаючого пластового тиску від нагнітання. Чисельне ядро оцінює виникнення критичних напружень, запобігаючи нефізичній техногенній фільтрації крізь непроникні пласти.

Остаточним етапом V&V системи є перевірка чисельного ядра на стійкість в екстремальних та аварійних режимах.

1. Рівень 6 — Стрес-тести екстремальних фізичних сценаріїв (Adversarial Physical Emergence Tests)

Шостий рівень V&V системи призначений для перевірки надійності чисельного ядра в умовах екстремальних градієнтів, фазових переходів першого роду та фізичних катастроф.

7.1 Імпульсний шок запуску (t = 0^+ Impulse Test)

Тест моделює миттєвий запуск нагнітальної свердловини з нуля до максимального дебіту Q_{\text{max}} за нульовий проміжок часу.

* Виклики: Виникнення високочастотних чисельних мод та критичних градієнтів тиску у придепресійній зоні свердловини.
* Реакція ядра: Автоматичний алгоритм адаптивного дроблення часового кроку (Sub-stepping) повинен миттєво зменшити \Delta t, а чисельна схема інтегрування на основі L-стабільних методів має пригнітити чисельну осциляцію тиску без зупинки розрахунку.

7.2 Тест появления та зникнення фази (Phase Boundary Appearance Test)

Сценарій моделює виникнення або повне зникнення газової чи рідкої фази в комірці пласта (S_g = 0 \to S_g > 0 або S_o > 0 \to S_o = 0).

             ПЕРЕКЛЮЧЕННЯ ФАЗОВИХ СТАНІВ (S_g = 0 <-> S_g > 0)
    +---------------------------+                   +---------------------------+
    |   Однофазний стан (нафта) |                   |    Двофазний стан (L + V) |
    |   Первинна змінна: P, z_i |                   |    Первинні змінні: P, S_g|
    +---------------------------+                   +---------------------------+
                  |                                               ^
                  |    Виділення вільного газу (P < P_sat)        |
                  +-----------------------------------------------+
                  |  * Гарантія C^1-неперервності Якобіана        |
                  |  * Відсутність зациклення Ньютона-Рафсона     |

* Алгоритм заміни первинних змінних (Primary Variable Substitution):
  * При виникненні нової фази первинна змінна змінюється з мольної частки z_i на фазову насиченість S_g.
  * При зникненні фази (S_g \le 0) відбувається зворотне переключення на загальний склад z_i.
  * Алгоритм переключення гарантує C^1-неперервність елементів матриці Якобіана на межі фазового переходу, що виключає осциляції або розбіжність ітерацій Ньютона-Рафсона.

7.3 Тест перколяційного катастрофічного забивання пор (Verma-Pruess Limit Test)

Тест моделює випадання солей або завислих речовин при інжекції флюїдів, що призводить до критичного падіння пористості комірок до порога замикання \phi \le \phi_c.

* Степенова математична залежність Верми-Прюсса:

k(\phi) = k_0 \cdot \left( \frac{\phi - \phi_c}{1 - \phi_c} \right)^\eta

де k_0 — початкова проникність, \phi_c — критична пористость перколяційного замикання (типово \phi_c \in [0.01, 0.05]), \eta — критичний показник степеня (\eta \approx 3.0-8.0).

* Реакція ядра: При прямуванні \phi \to \phi_c проникність k(\phi) \to 0, дебіт через грані комірки блокується, а контролер кроку адаптивно скорочує часовий крок \Delta t \to 0, запобігаючи виродженню СЛАР чи діленню на нуль у коді Rust.

7.4 Тест аварійного затору НКТ гідратами (Hydrate Blockage in Tubing)

Сценарій моделює вихід термодинамічного профілю тиску та температури (P-T) у стовбурі свердловини всередину конверта утворення клатратних гідратів (модель ван дер Ваальса - Платтеу).

                     КОНВЕРТ УТВОРЕННЯ ГІДРАТІВ У СВЕРДЛОВИНІ
    P (Тиск)
     ^
     |              / Зона утворення гідратів
     |             /  (van der Waals - Platteeuw)
     |            /
     |           /   * P-T Профіль свердловини перетинає межу
     |          /      -> Діаметр D_tubing -> 0 (Блокування)
     |         /       -> Коректне перенаправлення потоків
     +----------------------------------------------------------> T (Температура)

* Фізичний процес та реакція ядра:
  1. При перетині термодинамічною кривою межі фазової стабільності гідратів свердловинний сателіт розраховує зменшення ефективного гідравлічного діаметра НКТ (D_{\text{tubing}} \to 0).
  2. Сателіт свердловини динамічно перераховує коефіцієнт припливу (Well Index — WI) та коефіцієнт шорсткості стінок, дроселюючи приплив флюїду зі свердловини.
  3. Гідродинамічне ядро пласта коректно обробляє зростання протитиску, перенаправляючи фільтраційні потоки у пластовій сітці без паніки системи чи зупинки симуляції.

Регламент впровадження V&V системи у CI/CD пайплайн розробки Rust-ядра

Специфікована 6-рівнева система верифікації та валідації інтегрується в автоматизований CI/CD пайплайн розробки чисельного ядра 3D THMC симулятора на Rust з суворими часовими бюджетами виконання.

[ Git Push / PR ]
       |
       v
+-------------------------------------------------------------------+
| 1. Компіляція та стат. аналіз (Cargo Check / Clippy / Unit)       |
+-------------------------------------------------------------------+
       |
       v
+-------------------------------------------------------------------+
| 2. Рівні 1-3: Аналітичні бенчмарки, Масовий баланс (<10^-12),      |

+-------------------------------------------------------------------+
       |
       v

+-------------------------------------------------------------------+
       |
       v
+-------------------------------------------------------------------+

[ Деплой у Продакшн Ядро ]

Часові бюджети та регламент CI/CD:

1. Pull Request Smoke Suite (Рівні 1–3):

* Бюджет: < 3 хвилин.
* Перевірки: Повна відсутність panic!, перевірка точних аналітичних розв'язків, аудит збереження маси з точністю < 10^{-12}, TPD тест Міхельсена на 10 000 точках.
* Стратегія обробки помилок у Rust: Збірний модуль внутрішніх розв'язувачів компілюється з panic = "abort". Будь-яка чисельна розбіжність перехоплюється через суворе повернення типу Result<T, NumericalDivergenceError>, що гарантує детерміноване завершення тестів без незапланованого падіння процесів.

2. Nightly Regression Suite (Рівні 4–5):

* Бюджет: < 45 хвилин.
* Перевірки: Верифікація порядків часової збіжності O(\Delta t) та O(\Delta t^2), стабільність Fixed-Stress split (N_{\text{iter}} \le 5), повне проходження промислових бенчмарків SPE 1, SPE 3, SPE 5, SPE 9.

3. Pre-Release Stress & Scale Suite (Рівні 5–6):

* Бюджет: < 3 годин.
* Перевірки: Великомасштабний апскейлінг SPE 10 (1.1 \times 10^6 комірок) на багатоядерних вузлах, геомеханіка SPE 11, повний спектр аверсаріальних стрес-тестів (імпульсний шок t=0^+, фазові переходи, забивання пор за Вермою-Прюссом k(\phi) \to 0, гідратний затор НКТ).

Послідовне виконання вимог даної 6-рівневої V&V системи гарантує математичну точність, термодинамічну узгодженість та абсолютну обчислювальну надійність композиційного симулятора в умовах реальної промислової експлуатації.
