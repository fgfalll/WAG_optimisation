1. Інтеграційна архітектура та зв'язок із Базовим Дизайн-Документом і Доповненням 1

Розробка високопродуктивного обчислювального комплексу 3D THMC (Термо-Гідро-Механо-Хімічного) моделювання вимагає розширення розрахункового ядра спеціалізованими модулями реального часу для обчислення аварійних ситуацій та ремонтно-відновлювальних робіт. Стандартні симулятори розробки родовищ базуються на припущенні про квазістаціонарну зміну режимів фільтрації та статичні характеристики приповерхневих зон. Однак під час технологічних впливів — таких як кислотні обробки, закачування розчинників, глушіння свердловин при газонафтоводопроявах (ГНВП) або екстрене спрацьовування підземних клапанів безпеки — граничні умови пластової системи змінюються ударним, дискретним чином.

З обчислювальної точки зору, Addendum 2 модифікує класичну глобальну систему диференціальних рівнянь у частинних похідних (PDE) та звичайних диференціальних рівнянь (ODE), визначену в Основному Дизайн-Документі. Впровадження локалізованих динамічних граничних умов вимагає прямої інтеграції з нелінійним солвером Ньютона-Рафсона (Newton-Raphson PDE/ODE solver loop). При виникненні локальних технологічних обробок або аварійних фронтів модуль виконує цільове перескладання локальних елементів розрідженої матриці Якобі (Jacobian matrix assembly) без повного інвалідування глобального топологічного каркасу сітки. У зоні активного впливу (наприклад, у фронті розчинення кислотою або каналі зсувного вимивання) запускається динамічна просторова адаптивна адаптація сітки (mesh re-discretization), що дозволяє розв'язувати розривні граничні задачі без втрати коефіцієнту збіжності солвера.

Архітектурний вибір мови програмування Rust для реалізації ядра симулятора є строго обґрунтованим рішенням у контексті системного проектування HPC (High-Performance Computing). Асинхронна обробка миттєвих аварійних граничних умов вимагає виконання обчислень у багатопотоковому середовищі з нульовими витратами на синхронізацію (zero-cost abstractions). Строга система володіння та запозичення ресурсів (ownership and borrowing mechanism) гарантує абсолютну безпеку роботи з пам'яттю (memory safety) та відсутність станів гонитви даних (data-race-free parallelism) при паралельному перерахунку локальних матриць провідності. Реалізація маркерних трейтів Send та Sync дозволяє безпечно розподіляти просторові піддомени розрахункової сітки між потоками CPU, забезпечуючи високу локальність даних у кеш-пам'яті без залучення пауз на збирання сміття (Garbage Collection overhead).

Забезпечивши фундаментальний системний рівень для обробки дискретних граничних умов, перейдемо до детального математичного опису фізико-хімічних механізмів відновлення фільтраційних властивостей привибійної зони.

1. Модуль боротьби з пошкодженнями привибійної зони та закольматованності (Damages Remediation Module)

Падіння продуктивності свердловин переважно обумовлене формуванням пошкодженої привибійної зони пласта (ПЗП), викликаної кольматацією пористих каналів дрібнодисперсним шламом, осадженням важких фракцій нафти або утворенням нафтової фільтраційної кірки. Динамічний перерахунок коефіцієнта пошкодження (скін-фактора S(t)) та ефективного тензора проникності k_{eff}(t) в процесі відновлювальних обробок є критичною умовою точного моделювання дебітів.

2.1. Матричні та солянокислотні обробки (Matrix Acidizing)

Кінетика розчинення мінеральної матриці карбонатних або теригенних колекторів під дією солянокислотних/глинокислотних сумішей описується виразом Лазаги (Lasaga kinetics). Джерельний терм розчинення мінеральної фази R_{dissolution} > 0 визначається як:

R_{dissolution} = k_{acid} \cdot A_{sp} \cdot \left( C_{acid} - C_{eq} \right)^n

де k_{acid} — константа швидкості хімічної реакції [м/с], A_{sp} — питома реакційна площа поверхні мінералу на одиницю об'єму [м^{-1}], C_{acid} — поточна молярна концентрація активної кислоти [моль/м^3], C_{eq} — рівноважна концентрація продуктів реакції [моль/м^3], n — порядок хімічної реакції.

Руйнування фільтраційної кірки h_{cake}(t) під дією кислотного розчинника описується рівнянням експоненціальної деградації товщини шару кольматанту:

h_{cake}(t) = h_{cake,0} \cdot \exp\left( -\lambda_{acid} \cdot C_{acid} \cdot t \right)

де h_{cake,0} — початкова товщина фільтраційної кірки [м], \lambda_{acid} — коефіцієнт ефективності розчинення [м^3/(моль·с)]. Зниження скін-фактора перфораційних каналів до від'ємних значень (S_{perf} < 0), що моделює утворення високопровідних каналів розчинення (червоточин / wormholes), описується рівнянням:

S_{perf}(t) = S_0 - \alpha_{acid} \cdot \ln\left( \frac{r_{w,eff}(t)}{r_w} \right)

де S_0 — вихідний скін-фактор, r_w — радіус свердловини по долоту [м], r_{w,eff}(t) — ефективний радіус свердловини з урахуванням довжини червоточин [м], \alpha_{acid} — безрозмірний коефіцієнт інтенсивності каналоутворення.

2.2. Закачування ароматичних розчинників (Asphaltene/Wax Solvents — Toluene/Xylene)

Осадження органічних кольматантів (асфальтенів, парафінів) змінює фазову рівновагу системи. Закачування розчинників (толуолу, ксилолу) коригує глобальний параметр розчинності нафтової фази \delta_{oil}:

\delta_{oil}(t) = x_{solv} \cdot \delta_{solv} + (1 - x_{solv}) \cdot \delta_{oil,0}

де x_{solv} — мольна частка закачаного розчинника у рідкій фазі, \delta_{solv} та \delta_{oil,0} — параметри розчинності Hildebrand для розчинника та первинної нафти відповідно [Па^{0.5}]. Кинетика зворотного розчинення осадженої фази асфальтенів (S_a \to 0) описується рівнянням:

\frac{d S_a}{d t} = - k_{solv} \cdot S_a \cdot \max\left(0, \, \delta_{oil} - \delta_{crit}\right)

де S_a — насиченість порогового об'єму осадженими асфальтенами, k_{solv} — константа швидкості розчинення [с^{-1}], \delta_{crit} — критичний параметр розчинності, вище якого відбувається десорбція.

Очищення порогових горловин викликає розширення ефективного радіуса пор r_{pore}(t) = r_{pore,0} \cdot \sqrt{1 - S_a}. У стовбурі свердловини паралельно розраховується відновлення внутрішнього діаметра насосно-компресорних труб (НКТ) D_{tubing}(z,t):

D_{tubing}(z,t) = D_{tubing,0} - 2 \cdot h_{dep}(z,t)

де D_{tubing,0} — початковий внутрішній діаметр НКТ [м], h_{dep}(z,t) — поточна товщина шар відкладень парафінів/асфальтенів уздовж координати z [м].

2.3. Зворотна промивка та дренаж (Backwashing / Reverse Flow Cleaning)

При виклику припливу (зміні напрямку вектора фільтрації на зворотний, u_r < 0) на поверхні пористого каналу виникають гідродинамічні зсувні напруження \tau_{shear}:

\tau_{shear} = \mu \cdot \frac{|u_r|}{\sqrt{k \cdot \phi}}

де \mu — динамічна в'язкість дренованого флюїду [Па·с], u_r — радіальна швидкість Дарсі [м/с], k — абсолютна проникність незабрудненої матриці [м^2], \phi — пористість пласта. Умовою механічного змиву фільтраційної кірки є перевищення зсувного напруження над межею плинності кольматованого шару: \tau_{shear} > \tau_{crit}.

Покроковий алгоритм розрахунку змиву кольматанту та оновлення тензорних станів розрахункових комірок реалізовано у вигляді наступної послідовності:

1. Оновлення Вектора Швидкості: Обчислити локальний вектор швидкості Дарсі u_r для кожної приповерхневої комірки розрахункової сітки.
2. Перевірка Напрямку Потоку: Якщо u_r < 0 (напрямок фільтрації з пласта у свердловину), ініціювати розрахунок зсувних сил на границі.
3. Обчислення Сили Зсуву: Розрахувати \tau_{shear} = \mu \cdot \frac{|u_r|}{\sqrt{k \cdot \phi}} для поточного стану флюїду.
4. Обчислення Деградації Кірки: Якщо \tau_{shear} > \tau_{crit}, обчислити зміну товщини кірки за крок за часом \Delta t: \Delta h_{cake} = -\kappa_{wash} \cdot (\tau_{shear} - \tau_{crit}) \cdot \Delta t де \kappa_{wash} — коефіцієнт змиваємості шламу [м/(Па·с)].
5. Модифікація Стан-Вектора Тензора Проникності та Пористості: Оновити абсолютну пористість \phi(t) = \phi_0 + \Delta \phi_{strip} та перерахувати діагональні компоненти тензора проникності k_{ij}(t): k_{r}(t) = k_0 \cdot \left(1 - \frac{h_{cake}(t)}{r_{pore}}\right)^{-4} k_{ij}(t) = k_{ij,0} \cdot \frac{f(\phi(t))}{f(\phi_0)}

Перехід від механічних та Acid/Solvent обробок пласта до розблокування фазово-заблокованих зон і селективного перерозподілу потоків вимагає моделювання складних термодинамічних процесів.

1. Модуль боротьби з газовими гідратами та ізоляції проривів (Hydrate Remediation & Conformance Control)

Утворення техногенних газових гідратів у стовбурі свердловини та ПЗП призводить до формування заблокованих зон з нульовою фазовою проникністю, створюючи загрозу аварійної зупинки свердловини. Водночас передчасні прориви пластових вод або вільного газу через високопромиті пропластки суттєво знижують коефіцієнт охоплення пласта витісненням.

3.1. Хімічне та термічне розкладання гідратів (Hydrate Dissolution via THI & Heating)

Термодинамічна рівновага гідратоутворення розраховується на основі статистичної моделі ван дер Ваальса — Платтеу. Закачування термодинамічних інгібіторів (THI: метанол, моноетиленгліколь — MEG) знижує активність води a_{water}, що викликає зсув рівноважної температури \Delta T_{eq}:

\Delta T_{eq} = \frac{R \cdot T_{0}^2}{\Delta H_{hy}} \cdot \ln\left( a_{water} \right)

де R — універсальна газова стала [Дж/(моль·К)], T_0 — вихідна температура рівноваги чистої води [К], \Delta H_{hy} — питома ентальпія розкладу гідрату [Дж/моль]. Активність води a_{water} обчислюється через масову частку інгібітора w_{THI}.

Для оцінки рівноважної фугітивності газу f_{g,eq}(T, w_{THI}) розрахункове ядро симулятора використовує кубічні рівняння стану Пенга-Робінсона (PR-EOS) або Соаве-Редліха-Квонга (SRK-EOS) із класичними правилами змішування ван дер Ваальса (k_{ij} binary interaction parameters):

P = \frac{R T}{v - b_{mix}} - \frac{a_{mix}(T)}{v^2 + 2b_{mix}v - b_{mix}^2} \quad \text{(PR-EOS)}

Кінетика танення гідратної пробки описується від'ємним джерельним термом Бішної-Енглезоса (\frac{dn_H}{dt} < 0):

\frac{dn_H}{dt} = - k_{decomp} \cdot A_{hy} \cdot \left( f_{g,eq}(T, w_{THI}) - f_g \right) < 0

де k_{decomp} — константа швидкості розкладу гідратів [моль/(м^2·Па·с)], A_{hy} — площа реакційної поверхні гідратної фази [м^2], f_g — поточна фугітивність газової фази в порах [Па].

3.2. Депресійне розплавлення гідратів (Depressurization)

При зниженні тиску у стовбурі НКТ нижче рівноважного значення (P_{tubing} < P_{eq}(T)) порушується фазова рівновага кристалогідрату. Кристалічна ґратка розпадається на вільний газ та воду з поглинанням прихованої теплоти фазового переходу. Це викликає локальне охолодження, яке інтегрується в глобальне рівняння збереження енергії THMC ядра через джерельний терм q_{thermal}:

q_{thermal} = \Delta H_{hy} \cdot \frac{dn_H}{dt}

3.3. Ізоляція водо- та газоприпливу (Conformance Control / Water & Gas Shut-Off)

Для вирівнювання профілю приймальності та блокування вимитих каналів застосовується закачування зшитих полімерних гелів та піносистем. Фізика процесу полягає у селективному заповненні гелеутворювачем високопроникних каналів ("thief zones") з наступною полімеризацією, що знижує проникність каналу до нульових значень (k_{thief} \to 0).

Відповідно до джерельного контексту фільтраційних обмежень, підсумковий коефіцієнт витіснення RF(t) обмежується об'ємом прокачаного агента (HCPVI — Hydrocarbon Pore Volume Injected):

RF(t) \le RF_{\text{ult}}(\bar{P}_{\text{res,eff}}) \cdot \left(1 - \exp\left(-\frac{\text{HCPVI}}{\tau}\right)\right)

де \tau \approx 1.5 — безрозмірний параметр запізнення витіснення, \bar{P}_{\text{res,eff}} — середньозважений за видобутком пластовий тиск. Динаміка післяпроривного часткового мольного потоку газу f_g(t) розраховується за відносними фазовими проникностями:

f_g(t) = \frac{1}{1 + \left(\frac{1 - S_w(t) - S_g(t)}{S_g(t) - S_{gc}}\right) \cdot \frac{\mu_g}{\mu_o}}

де S_{gc} — критична насиченість газом, \mu_g, \mu_o — в'язкості газу та нафти.

1. Модуль ліквідації аварійних ситуацій та глушіння свердловин (Well Kill & Accident Control)

Неконтрольовані газонафтоводопрояви (ГНВП) є найнебезпечнішими аварійними ситуаціями при бурінні та експлуатації. Динамічне моделювання процесу глушіння свердловини необхідне для запобігання відкритим фонтанам та руйнуванню стовбура.

4.1. Моделювання глушіння свердловин при ГНВП (Well Kill Operations / Dynamic Blowout Control)

Розрахунок закачування важкого розчину глушіння (Heavy Kill Mud) базується на багатофазній Drift-Flux моделі. Модель враховує фазове ковзання (phase slip velocity) газу у висхідному потоці:

u_g = C_0 \cdot u_m + u_d

де u_g — абсолютна швидкість газової фази [м/с], C_0 — коефіцієнт розподілу профілю потоку (profile parameter, \approx 1.05 \dots 1.2), u_m — середня швидкість суміші [м/с], u_d — швидкість дрейфу бульбашок (drift velocity) [м/с].

Рівняння збереження імпульсу суміші визначає динаміку змінення гідростатичного протитиску P_{hydro}(z, t):

P_{hydro}(z, t) = \int_{0}^{z} \rho_{m}(z', t) \cdot g \, dz'

де \rho_m(z, t) = \alpha_g \rho_g + (1 - \alpha_g) \rho_{mud} — локальна густина суміші [кг/м^3], \alpha_g — об'ємна частка газу (gas void fraction). Умовою успішного глушіння неусталеного фонтану є перевищення сумарного тиску в стовбурі над поточним пластовим:

P_{hydro}(z_{bottom}, t) + \Delta P_{fric}(Q_{kill}) > P_{res}

де \Delta P_{fric} — гідравлічні втрати тиску на тертя при подачі насосів Q_{kill} [Па].

4.2. Спрацьовування підземних клапанів безпеки (SSSV Emergency Shutdown)

При перевищенні закритичного дебіту або падінні гирлового тиску нижче порогу спрацьовує підземний клапан безпеки (SSSV). Логіка безпеки (Safety Logic) автоматично перемикає стан граничної умови на ShutIn:

IF P_tubing < P_sssv_trigger OR Q_gas > Q_critical THEN
    Set BoundaryCondition = ShutIn
    Set SSSV_Valve_State = Closed
END IF

Закриття клапана на глибині z = z_{sssv} викликає хвильовий процес гідравлічного удару (water hammer). Динаміка згасання хвиль тиску та швидкості описується системою диференціальних рівнянь:

\frac{\partial P}{\partial t} + \rho \cdot a^2 \cdot \frac{\partial u}{\partial z} + \gamma_{damp} \cdot P = 0

\frac{\partial u}{\partial t} + \frac{1}{\rho} \cdot \frac{\partial P}{\partial z} + \frac{f_w \cdot u \cdot |u|}{2 D_{tubing}} = 0

з наступною суворою просторово-часовою граничною умовою в точці встановлення клапана z = z_{sssv}:

u(z_{sssv}, \, t) = 0, \quad \forall t \ge t_{close}

де a — швидкість звуку в середовищі [м/с], f_w — коефіцієнт тертя Дарсі-Вайсбаха, \gamma_{damp} — коефіцієнт в'язкого затухання [с^{-1}].

Після зупинки аварійного фонтанування виникає необхідність тривалого відновлення механічної цілісності затрубного простору.

1. Ремонтно-ізоляційні роботи та відновлення герметичності (Well Integrity Restoration)

Порушення герметичності цементного каменю викликає затрубні перетікання та міжколонні тиски. Модуль РІР розраховує процес відновлення цілісності затрубного простору шляхом продавлювання цементних шламів або полімерних смол під тиском (Squeeze Cementing).

5.1. Закачування цементу та смол під тиском (Squeeze Cementing & Leak Sealing)

Механіка ізоляції мікро-анулюсів та тріщин полягає в заповненні каналів розкриттям w_{micro} реологічно складною суспензією. Під дією тиску продавлювання P_{squeeze} відбувається віджимання рідкої фази та зменшення розкриття каналу:

w_{micro}(t) \to 0

Зміна проникності затрубного мікро-анулюсу k_{micro}(t) розраховується за кубічним законом для плоских тріщин:

k_{micro}(t) = \frac{w_{micro}(t)^2}{12} \to 0

Динамічна в'язкість цементного розчину або смоли \mu_{squeeze}(t) у процесі структуроутворення описується нелінійним рівнянням тужавіння з явним математичним обмеженням часового домену:

\mu_{squeeze}(t) = \mu_0 \cdot \left( 1 - \frac{t}{t_{setting}} \right)^{-m}, \quad \text{для } 0 \le t < t_{setting}

де \mu_0 — початкова в'язкість розчину [Па·с], t_{setting} — час початку тужавіння [с], m — показник структуроутворення. Зазначене обмеження 0 \le t < t_{setting} усуває сингулярність (ділення на нуль) у чисельному солвері.

Усі розраховані нелінійні динамічні параметри (в'язкість \mu_{squeeze}, товщина кірки h_{cake}, гідростатичний тиск P_{hydro}, розкриття тріщин w_{micro}) серіалізуються в незмінні (immutable), потокобезпечні структури даних Rust DTO для передачі між обчислювальними потоками без виникнення станів гонитви.

1. Математична специфікація Вхідних DTO-Структур на Rust (Input DTO Architecture)

Для передачі параметрів реабілітації з графічного інтерфейсу або оптимізаційного модуля в розрахункове ядро використовується суворо типізована архітектура DTO-структур на мові Rust. Код реалізовано з використанням атрибутів serde для гарантії серіалізації/десеріалізації zero-copy та строгих перевірок валідації через виділений тип помилки RemediationValidationError.

use serde::{Deserialize, Serialize};
use std::fmt;

/// Строго типізований перелік помилок валідації DTO параметрів ремонтних робіт.
# [derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub enum RemediationValidationError {
    InvalidSolventInjectionRate(String),
    InvalidAcidVolumeConcentration(String),
    InvalidInhibitorMassFraction(String),
    InvalidKillMudDensity(String),
    InvalidKillPumpRate(String),
    InvalidSssvTriggerPressure(String),
    InvalidSqueezeCementViscosity(String),
}

impl fmt::Display for RemediationValidationError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            Self::InvalidSolventInjectionRate(msg) => write!(f, "Solvent Rate Error: {}", msg),
            Self::InvalidAcidVolumeConcentration(msg) => write!(f, "Acid Concentration Error: {}", msg),
            Self::InvalidInhibitorMassFraction(msg) => write!(f, "Inhibitor Fraction Error: {}", msg),
            Self::InvalidKillMudDensity(msg) => write!(f, "Kill Mud Density Error: {}", msg),
            Self::InvalidKillPumpRate(msg) => write!(f, "Kill Pump Rate Error: {}", msg),
            Self::InvalidSssvTriggerPressure(msg) => write!(f, "SSSV Pressure Error: {}", msg),
            Self::InvalidSqueezeCementViscosity(msg) => write!(f, "Cement Viscosity Error: {}", msg),
        }
    }
}

impl std::error::Error for RemediationValidationError {}

/// Потокобезпечна (Send + Sync) вхідна DTO-структура для параметризації
/// ремонтно-відновлювальних робіт та аварійного контролю.
# [derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct RemediationInputDTO {
    /// Об'ємна витрата закачування ароматичного розчинника (толуол/ксилол) [м3/с].
    /// Допустимий діапазон: [0.0, 0.1] м3/с.
    pub solvent_injection_rate: f64,

    /// Об'ємна концентрація active acid у солянокислотному розчині [безрозмірна].
    /// Допустимий діапазон: [0.0, 1.0].
    pub acid_volume_concentration: f64,

    /// Масова частка інгібітора гідратоутворення (Метанол/MEG) [безрозмірна].
    /// Допустимий діапазон: [0.0, 1.0].
    pub inhibitor_mass_fraction: f64,

    /// Густина важкого бурового розчину для глушіння свердловини [кг/м3].
    /// Допустимий діапазон: [800.0, 3000.0] кг/м3.
    pub kill_mud_density: f64,

    /// Об'ємна подача насосного агрегату при глушінні свердловини [м3/с].
    /// Допустимий діапазон: [0.0, 0.2] м3/с.
    pub kill_pump_rate: f64,

    /// Пороговий тиск спрацьовування підземного клапана безпеки SSSV [Па].
    /// Допустимий діапазон: (0.0, 1.0e8] Па.
    pub sssv_trigger_pressure: f64,

    /// Початкова динамічна в'язкість цементного розчину або смоли для РІР [Па·с].
    /// Допустимий діапазон: (0.001, 100.0] Па·с.
    pub squeeze_cement_viscosity: f64,
}

impl RemediationInputDTO {
    /// Валідація фізичних меж вхідних параметрів відповідно до специфікації.
    /// Повертає `Ok(())` або конкретизовану помилку `RemediationValidationError`.
    pub fn validate(&self) -> Result<(), RemediationValidationError> {
        if !(0.0..=0.1).contains(&self.solvent_injection_rate) {
            return Err(RemediationValidationError::InvalidSolventInjectionRate(
                format!("Value {} m3/s out of range [0.0, 0.1]", self.solvent_injection_rate)
            ));
        }
        if !(0.0..=1.0).contains(&self.acid_volume_concentration) {
            return Err(RemediationValidationError::InvalidAcidVolumeConcentration(
                format!("Value {} out of range [0.0, 1.0]", self.acid_volume_concentration)
            ));
        }
        if !(0.0..=1.0).contains(&self.inhibitor_mass_fraction) {
            return Err(RemediationValidationError::InvalidInhibitorMassFraction(
                format!("Value {} out of range [0.0, 1.0]", self.inhibitor_mass_fraction)
            ));
        }
        if !(800.0..=3000.0).contains(&self.kill_mud_density) {
            return Err(RemediationValidationError::InvalidKillMudDensity(
                format!("Density {} kg/m3 out of range [800.0, 3000.0]", self.kill_mud_density)
            ));
        }
        if !(0.0..=0.2).contains(&self.kill_pump_rate) {
            return Err(RemediationValidationError::InvalidKillPumpRate(
                format!("Pump rate {} m3/s out of range [0.0, 0.2]", self.kill_pump_rate)
            ));
        }
        if self.sssv_trigger_pressure <= 0.0 || self.sssv_trigger_pressure > 1.0e8 {
            return Err(RemediationValidationError::InvalidSssvTriggerPressure(
                format!("Trigger pressure {} Pa out of range (0.0, 1.0e8]", self.sssv_trigger_pressure)
            ));
        }
        if self.squeeze_cement_viscosity < 0.001 || self.squeeze_cement_viscosity > 100.0 {
            return Err(RemediationValidationError::InvalidSqueezeCementViscosity(
                format!("Viscosity {} Pa*s out of range [0.001, 100.0]", self.squeeze_cement_viscosity)
            ));
        }
        Ok(())
    }
}
