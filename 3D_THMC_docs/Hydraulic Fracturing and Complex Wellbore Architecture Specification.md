Технічна специфікація симулятора на Rust: Модулі гідравлічного розриву пласта (ГРП) та комплексної конструкції свердловини

1. Загальні архітектурні вимоги та системна інтеграція симулятора на Rust

1.1. Архітектура модулів та інтеграція з сіткою FVM/FEM за моделлю EDFM

Симулятор розробляється як високопродуктивна обчислювальна система (HPC) мовою Rust, призначена для моделювання складної фільтрації, термодинаміки та гідродинаміки у пласті та стовбурі свердловини. Інтеграція геометрії дискретних тріщин у тривимірну сітку скінченних об'ємів (FVM) або скінченних елементів (FEM) виконується на основі моделі вбудованих дискретних тріщин (Embedded Discrete Fracture Model — EDFM).

При застосуванні EDFM тріщини геометрично перетинають матричну сітку FVM/FEM без необхідності перебудови сітки (unstructured re-meshing). Перенос маси та енергії між матрицею пласта та тріщиною розраховується через обчислення коефіцієнтів геометричної провідності (transmissibility factors) на графі геометричного перетину.

Стратегія паралелізації та керування пам'яттю у Rust (HPC Paradigm):

1. Багатопотокова паралелізація: Модуль розрахунку EDFM та збирання глобальної матриці проводимо із застосуванням паралелізму по даних через бібліотеку rayon для обчислення провідностей та міжфазних потоків по мільйонах осередків сітки FVM. Для координації асинхронних завдань введення-виведення та обміну повідомленнями між потоками використовується tokio / crossbeam.
2. Арена-алокація та Zero-Copy паттерни: Забороняється динамічне виділення пам'яті в купі (heap allocation) окремо для кожного осередку в обчислювальних циклах. Мережевий стан зберігається у суцільних плоских векторах Vec<T> або спеціалізованих аренах пам'яті (typed-arena). Оновлення векторів стану пласта на кожному часовому кроці здійснюється через неволодіючі зрізи &[T] та &mut [T] (zero-copy slicing) для уникнення cache-misses та затримок Garbage Collection.
3. Обробка помилок (Error Handling): Жодна нечисельна збіжність не повинна викликати panic!. Всі математичні та обчислювальні методи повертають стандартний Result<T, SimulatorError>.

Системні типи даних та інтерфейси Rust (struct, enum, trait):

pub enum SimulatorError {

    MatrixInversionError(String),
    EDFMGeometryError(String),
    ProppantTransportError(String),
    WellboreHydraulicsError(String),

impl fmt::Display for SimulatorError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {

            SimulatorError::FlashConvergenceError(msg) => write!(f, "Flash Convergence Error: {}", msg),
            SimulatorError::MatrixInversionError(msg) => write!(f, "Matrix Inversion Error: {}", msg),
            SimulatorError::EDFMGeometryError(msg) => write!(f, "EDFM Geometry Error: {}", msg),
            SimulatorError::ProppantTransportError(msg) => write!(f, "Proppant Transport Error: {}", msg),
            SimulatorError::WellboreHydraulicsError(msg) => write!(f, "Wellbore Hydraulics Error: {}", msg),
        }
    }
}

1.2. Термодинамічне ядро фазової рівноваги (EoS та Delumping)

Термодинамічне ядро симулятора виконує розрахунки фазової рівноваги (VLE) та ізотермічної спалах-флеш фільтрації (Isothermal Flash Calculations) у широкому діапазоні тисків та температур. Модуль підтримує:

1. Трипараметричні кубічні рівняння стану Пенга-Робінсона (PR EoS) та Соаве-Редліха-Квонга (SRK EoS);
2. Модифікації із зсувом об'єму залежно від температури (VT-PR, VT-SRK) для підвищення точності розрахунку густини рідкої фази;
3. Модель PC-SAFT для умов екстремально високих температур і тисків (HTHP: тиск 7–276 МПа / 1,000–35,000 psi, температура 278–533 К / 40–500 °F).

Чисельні алгоритми VLE Flash Solver:

Перед виконанням розрахунку спалаху флеш-ітерацією чисельне ядро зобов'язане реалізувати двокроковий алгоритм:

1. Тест фазової стабільності Міхельсена (Michelsen's Phase Stability Test): Пошук стаціонарних точок функції зведеної відстані до дотичної площини (Tangent Plane Distance — TPD). Фаза вважається нестабільною та розщеплюється на дві, якщо TPD(y) < 0 для будь-якої пробної фазової концентрації y.
2. Алгоритм Рачфорда-Ріса (Rachford-Rice Root-Finding): При наявності двофазного стану частка парової фази V розраховується через знаходження кореня функції Рачфорда-Ріса методом Ньютона-Рафсона з обмеженням кроку: f(V) = \sum_{i=1}^{N_c} \frac{z_i (K_i - 1)}{1 + V (K_i - 1)} = 0 де z_i — загальна мольна частка i-го компонента, K_i = y_i / x_i — константа фазового розподілу, що коригується на кожному кроці через коефіцієнти фугітивності \phi_i^V та \phi_i^L.

Для деталізації компонентного складу під час поєднання двофазного моделювання пласта з поверхневою інфраструктурою використовується чисельний метод делампінгу (Delumping Mix-Method), який забезпечує узгодженість із детальними експериментальними PVT-даними та аналітичним підходом Нікіти (Nichita's analytical approach).

1.3. Інтеграція з сурогатним рушієм та алгоритмами GEP (Gene Expression Programming)

Симулятор інтегрується з оптимізаційним сурогатним рушієм на основі алгоритму програмування експресії генів (Gene Expression Programming — GEP).

1. Кодування хромосом: Хромосоми кодуються у вигляді лінійних символьних стрічок фіксованої довжини, що складаються з одного або кількох генів одинакової довжини.
2. Структура гена: Кожен ген ділиться на голову h (містить функції F та термінали T) та хвіст t (містить виключно термінали T). Довжина хвоста t визначається формулою: t = h \cdot (n_{\text{max}} - 1) + 1 де n_{\text{max}} — максимальна арність функцій у наборі F. Для обробки чисельних констант використовується додатковий домен D_c.
3. Трансляція (K-вирази у Дерева Виразів — ET): Зчитування відкритої рамки зчитування (ORF) мовою Karva виконується послідовно (зліва направо, зверху вниз по рівнях дерева виразів). Залишок гена поза межами активного ORF вважається некодуючою ділянкою.
4. Зв'язування геномів: Піддерева sub-ET, згенеровані окремими генами, об'єднуються у мультимодульне дерево за допомогою функцій зв'язування (додавання, множення або логічна функція IF).
5. Генетичні оператори:

* Мутація: Заміна будь-якого символу в голові на функцію/термінал, а у хвості — лише на термінал.
* IS-транспозиція (Insertion Sequence): Копіювання короткого фрагмента з довільного місця у голову гена (крім кореня).
* RIS-транспозиція (Root IS): Копіювання фрагмента, що починається з функції, у корінь гена.
* Транспозиція генів: Переміщення цілого гена в початок хромосоми.
* Рекомбінація: Одноточкова, двоточкова та рекомбінація цілих генів між двома батьківськими хромосомами.

Інтерфейс інтеграції Rust-to-GEP:

Взаємодія між сурогатним рушієм GEP та симулятором здійснюється через високоефективний пакетний конвеєр виконання (Batch Execution Pipeline) або C-ABI / FFI біндінги (unsafe extern "C"). Хромосоми GEP транслюються у вектор інструкцій байт-коду або компілюються в JIT-функції, які приймають матрицю станів осередків сітки &[MatrixCell] та повертають обчислені сурогатні значення вилучення/тиску без накладних витрат на середовище виконання Python.

1. Специфікація Модуля 1: Гідравлічний розрив пласта та транспорт пропану (Hydraulic Fracturing & Proppant Transport Module)

2.1. Динаміка геометрії тріщини ГРП (L_f, H_f, w_f)

Розрахунок еволюції тріщини під дією тиску закачування флюїду-пісконосія та геомеханічного поля напружень здійснюється за допомогою трьох геометричних моделей: Pseudo-3D (P3D), Planar-3D та Discrete Fracture Network (DFN).

Алгоритм динамічного оновлення геометрії на кожному часовому кроці \Delta t:

1. Обчислення чистого тиску (Net Pressure): p_{\text{net}}(x,z) = p_{\text{fluid}}(x,z) - \sigma_h(z), де \sigma_h — мінімальне горизонтальне напруження пласта [Па / psi].
2. Розрахунок розкриття w_f(x,z): w_f(x,z) = C_w \cdot \frac{1 - \nu^2}{E} \cdot p_{\text{net}}(x,z) \cdot H_f де E — модуль Юнга [Па / psi], \nu — коефіцієнт Пуассона [безрозмірний], C_w — геометричний коефіцієнт формы [безрозмірний].
3. Розрахунок зростання довжини L_f та висоти H_f: Швидкість просування фронту тріщини визначається локальним балансом маси флюїду та в'язкісно-критичною тріщиностійкістю породи K_{IC} [Па·м^{0.5} / psi·in^{0.5}]. У моделі P3D вертикальне зростання H_f через бар'єрні пласти обмежується стрибком напружень \Delta \sigma_h.

2.2. Транспорт, осадження пропану та формування пачки (Proppant Transport & Settling)

Перенос концентрованої суспензії пропану у гелі описується диференціальним рівнянням переносу-дифузії-осадження у часткових похідних: \frac{\partial (w_f C_p)}{\partial t} + \nabla \cdot (w_f C_p \mathbf{u}_p) - \frac{\partial}{\partial z} (w_f C_p v_{\text{settling}}) = 0 де C_p — об'ємна концентрація пропану [безрозмірна, 0..1], \mathbf{u}_p — вектор швидкості флюїду-носія [м/с / ft/s], v_{\text{settling}} — швидкість гравітаційного осадження [м/с / ft/s].

Явна чисельна дискретизація переносу пропану (TVD Scheme):

Для запобігання чисельній дифузії та осциляціям на фронті пропанової пачки просторова дискретизація конвективного члена виконується за протитоковою схемою високого порядку (Upwind TVD Scheme) з обмежувачами потоку (Flux Limiters, наприклад Superbee або Van Leer): F_{i+1/2} = F_{i+1/2}^{\text{Low}} + \phi(r_i) \left( F_{i+1/2}^{\text{High}} - F_{i+1/2}^{\text{Low}} \right) де \phi(r_i) — функція обмежувача потоку, r_i — співвідношення градієнтів концентрації. Апроксимація по часу виконується за явно-неявною схемою TVD Runge-Kutta.

1. Гравітаційне осадження: Опис осадження поодиноких частинок за Законом Стокса коригується на обмежений простір стінок тріщини та стеричну стесненість за моделлю Ґауера (Power-Gower model): v_{\text{settling}} = \frac{g d_p^2 (\rho_p - \rho_f)}{18 \mu_f} \cdot (1 - C_p)^n \cdot f_{\text{wall}}(w_f / d_p) де d_p — діаметр частинок пропану [м / in], \rho_p, \rho_f — густина пропану та флюїду [кг/м³ / lb/ft³], \mu_f — в'язкість флюїду [Па·с / cP], n — показник стесненого осадження (Power-Gower exponent) [безрозмірний].
2. Формування та ущільнення пачки (Proppant Pack Formation): Коли місцева концентрація досягає граничного значення ущільнення C_{p,\text{max}} \approx 0.58 - 0.63, осаджений пропан формує знерухомлену пропанову пачку у нижній частині тріщини. Розкриття w_f зафіксованої пачки під дією зімкнення стінок тріщини визначається механічною рівновагою ущільненого гранульованого середовища.

2.3. Динамічна провідність тріщини (k_f \cdot w_f) та деградація проникності

Під час експлуатації свердловини ефективна провідність тріщини k_f \cdot w_f зазнає деградації під дією ефективного напруження зімкнення (Closure Stress \sigma_{\text{closure}} = p_{\text{confining}} - p_{\text{pore}}).

Обчислення проникності k_f виконується за модифікованою моделлю Козені-Кармана (Kozeny-Carman) з урахуванням експериментальних деградаційних кривих StimLab: k_f(\sigma_{\text{closure}}) = k_{f,0} \cdot \Phi_{\text{crush}}(\sigma_{\text{closure}}) \cdot \Phi_{\text{embed}}(\sigma_{\text{closure}})

Вхідні та вихідні змінні модуля розрахунку провідності:

* Вхідні змінні:
  * w_f_initial — початкове розкриття тріщини під тиском, [м / ft / in / mm].
  * d_prop — середній діаметр частинок пропану, [м / in / mm].
  * sigma_closure — ефективне напруження зімкнення пласта, [Па / МПа / psi].
  * rock_youngs_modulus — модуль Юнга гірської породи, [Па / ГПа / psi].
  * proppant_strength — міцність пропану на роздавлювання, [Па / МПа / psi].
  * concentration_area — поверхнева концентрація укладки пропану, [кг/м² / lb/ft²].
  * gel_residue_damage — коефіцієнт пошкодження залишковим гелем, [безрозмірний, 0..1].
* Вихідні змінні:
  * w_f_effective — ефективне розкриття тріщини після вдавлювання, [мм / in / м].
  * k_f_effective — ефективна проникність пропанової пачки, [мД / Дарсі / m²].
  * fracture_conductivity — підсумкова провідність тріщини k_f \cdot w_f, [мД·м / D·ft / D·cm].

2.4. Гідродинаміка прориву флюїду та фільтраційна модель Коваля

Розрахунок просування фронту витіснення нафти розчинником (CO₂) та розрахунок часу прориву виконується з використанням моделі фракційного потоку Коваля (Koval model).

Коефіцієнт вилучення нафти RF(t) жорстко обмежується накопиченим об'ємом прокачування розчинника у порах (HCPVI — Hydrocarbon Pore Volume Injected): RF(t) \le RF_{\text{ult}}(\bar{P}_{\text{res,eff}}) \cdot \left(1 - \exp\left(-\frac{\text{HCPVI}}{\tau}\right)\right) де \tau = 1.5. Для відтворення фізично обґрунтованого вилучення при витісненні CO₂ встановлюється нижній поріг чистого використання газу (Net CO₂ Utilization Floor): \ge 2.5\text{ MSCF/STB} (або \ge 0.12\text{ t/STB}). Еталонний робочий діапазон чистого використання становить 0.25 - 0.50\text{ t/STB} (5 - 10\text{ MSCF/STB}).

Час прориву газу в елементі розробки (pattern) обчислюється за формулою: t_{\text{bt}} = \frac{V_{p,\text{pattern}} \cdot (1 - S_{wi})}{K_{\text{koval}} \cdot q_{\text{inj,pattern}}} де V_{p,\text{pattern}} — об'єм пор елемента розробки [м³ / bbl], S_{wi} — зв'язана водонасиченість [безрозмірна], K_{\text{koval}} — фактор неоднорідності та рухливості Коваля [безрозмірний], q_{\text{inj,pattern}} — темп нагнітання в один елемент [м³/с / MSCFD].

Штучні штрафні множники прориву (такі як result *= breakthrough_impact або жорсткі штрафи -1.0 \times 10^{12}) повністю вилучені з коду симулятора. Економічне депресування NPV при ранньому прориві відбувається природно через зростання витрат на рециркуляцію газу та компресію в моделі DCF.

1. Специфікація Модуля 2: Комплексна конструкція свердловини та закінчення (Complex Wellbore & Completion Architectural Module)

3.1. Деталізована геометрія стовбура свердловини та обсадних колон

Стовбур свердловини описується деталізованою багатоколонною геометричною конструкцією. Модуль зобов'язаний виконувати розрахунок та забезпечувати жорсткий контроль таких конструктивних елементів:

1. Кондуктор (Conductor);
2. Проміжні обсадні колони (Intermediate Casings);
3. Експлуатаційна колона (Production Casing);
4. Потайні колони / хвостовики (Liners);
5. Насосно-компресорні труби (Tubing).

Вимагається жорстке алгоритмічне дотримання специфікації геометричних та механічних параметрів для кожного сегмента: внутрішній діаметр D_{\text{in}} [м / in], зовнішній діаметр D_{\text{out}} [м / in], товщина стінки t_w [мм / in], середня абсолютна шорсткість сталевої поверхні (Steel Roughness \epsilon) [мм / in], а також інтервали спуску за глибиною по стовбуру (Measured Depth — MD) [м / ft] та по вертикалі (True Vertical Depth — TVD) [м / ft].

3.2. Цілісність цементного кільця (Cement Sheath Integrity)

Опис цементного кільця у затрубному просторі враховує геометрію та термо-геомеханічні характеристики:

* Товщина цементного камню у міжколонному просторі [мм / in];
* Модуль Юнга цементу E_{\text{cem}} [Па / GPa / psi], коефіцієнт Пуассона \nu_{\text{cem}} [безрозмірний];
* Міцність зчеплення цементу з обсадною колонною та гірською породою (Bond Strength) [Па / МПа / psi].

Модуль розраховує напружений стан цементного кільця при зміні внутрішньоколонного тиску та температури. При перевищенні межі міцності матеріалу алгоритм моделює утворення мікро-анулюсів (micro-annuli) та поздовжніх затрубних каналів витоку (leak paths), що призводить до міжпластових перетоків.

3.3. Динаміка перфораційної зони та обмеження продуктивності (IPR)

Перфораційний інтервал описується параметрами:

* Щільність перфорації (Shot Density) [отворів/м / shots/ft];
* Діаметр перфораційного отвору [мм / in] та глибина каналу L_p [мм / in];
* Кут фазування (Phasing Angle: 60°, 90°, 120°, 180°);
* Скін-фактор пошкодженої зони перфорації S_{\text{perf}} [безрозмірний].

Автоматичне розбиття та алгоритмічні обмеження продуктивності:

Для родовищ площею \text{Area} > 40\text{ акрів} за відсутності явно заданої сітки свердловин симулятор виконує автоматичне розбиття площі на елементи розробки (patterns): N_{\text{pat}} = \max\left(1, \text{round}\left(\frac{\text{Area}}{40\text{ акрів}}\right)\right) При цьому приймається рівність кількості свердловин: N_{\text{inj}} = N_{\text{prod}} = N_{\text{pat}}.

Продуктивність кожної окремої видобувної свердловини жорстко обмежується розрахунком за моделлю Дарсі/Вогеля (Darcy/Vogel IPR) до граничного значення: q_{o,\text{well}} \le 1,000\text{ BOPD на одну свердловину} Загальний польовий темп нагнітання та видобутку масштабується пропорційно кількості активних елементів розробки: q_{\text{inj,field}} = q_{\text{inj,pattern}} \times N_{\text{inj}} (у діапазоні 20,000–60,000 MSCFD для родовища, або 1,000–2,500 MSCFD на один елемент).

3.4. Багатосегментна гідравліка стовбура (Multi-Segment Drift-Flux Model)

Розрахунок багатофазного потоку (нафта, газ, вода) у НКТ та затрубному просторі виконується за багатосегментною моделлю Drift-Flux.

Декомпозиція градієнта тиску Drift-Flux:

Загальний градієнт тиску уздовж сегмента стовбура свердловини \frac{dp}{dz} розкладається на гідростатичну, фрикційну та акселераційну складові: \frac{dp}{dz} = \left(\frac{dp}{dz}\right)_{\text{hydrostatic}} + \left(\frac{dp}{dz}\right)_{\text{friction}} + \left(\frac{dp}{dz}\right)_{\text{accel}} \frac{dp}{dz} = \rho_m g \sin\theta + \frac{f_m \rho_m v_m^2}{2 D} + \rho_m v_m \frac{dv_m}{dz} де \rho_m = \alpha_g \rho_g + \alpha_l \rho_l — сумішева густина [кг/м³ / lb/ft³], v_m — сумішева швидкість [м/с / ft/s], f_m — коефіцієнт тертя Дорсі [безрозмірний], \theta — кут відхилення стовбура від горизонталі.

Швидкість газу v_g описується через коефіцієнт розподілу C_0 та швидкість дрейфу V_{gj}: v_g = C_0 v_m + V_{gj}

1. Неізотермічний теплообмін: Обчислення температурного профілю флюїду з урахуванням кондуктивного та конвективного теплообміну з вміщуючими гірськими породами через обсадні колони та цементне кільце.
2. Затрубні перетоки та свердловинне обладнання: Моделювання роботи регульованих клапанів припливу (Inflow Control Devices — ICD / Inflow Control Valves — ICV).
3. Динамічний фракційний потік газу після прориву: f_g(t) = \frac{1}{1 + \left(\frac{1 - S_w(t) - S_g(t)}{S_g(t) - S_{gc}}\right) \cdot \frac{\mu_g}{\mu_o}} Після прориву газу частка видобутого CO₂ у складі газу зростає до 30%–60% від об'єму нагнітання.
4. Динамічна еволюція газовмісту (\text{GOR}_{\text{co2}}): \text{GOR}_{\text{co2}}(t) = \frac{q_{\text{co2,prod}}(t)}{q_o(t)} Значення \text{GOR}_{\text{co2}} динамічно зростає у міру виснаження нафтового валу від початкових значень до 5,000–25,000 SCF/STB на пізній стадії розробки.
5. Динамічне зв'язування тиску пласта: Після розрахунку профілю тиску в пласті розраховується середньозважений за видобутком ефективний пластовий тиск: \bar{P}_{\text{res,eff}} = \frac{\sum_t P_{\text{res}}(t) \cdot q_o(t) \cdot \Delta t}{\sum_t q_o(t) \cdot \Delta t} Остаточний коефіцієнт вилучення RF та коефіцієнт змішуваності \omega перераховуються на основі \bar{P}_{\text{res,eff}}, замінюючи некориговані статичні параметри тиску.

6. Економіко-технічний модуль та уніфікація розрахунку NPV/CAPEX

4.1. Динамічна модель CAPEX та розрахунок інфраструктури

Капітальні витрати (CAPEX) розраховуються динамічно як функція від кількості нагнітальних (N_{\text{inj}}) та видобувних (N_{\text{prod}}) свердловин, кількості елементів розробки (N_{\text{patterns}}) і пікової потужності компресорної станції рециркуляції газу (Q_{\text{recycle,peak}}, MSCFD).

Компоненти та розрахункові формули CAPEX:

Компонент CAPEX Формула розрахунку / Залежність Залежні технологічні змінні
Буріння та облаштування свердловин N_{\text{inj}} \times \$1.5\text{M} + N_{\text{prod}} \times \$1.0\text{M} N_{\text{inj}}, N_{\text{prod}}
Маніфольди та промислові мережі N_{\text{patterns}} \times \$250\text{k} + \$3\text{M} (магістральний трубопровід) N_{\text{patterns}}

Базова інфраструктура та енергопостачання \$5\text{M} (фіксована базова ставка) Масштаб промислового майданчика

4.2. Уніфікована модель дисконтованого грошового потоку (DCF NPV)

Розрахунок NPV виконується шляхом прямого інтегрування річних операційних профілів видобутку та витрат.

Математичні рівняння грошового потоку та дисконтування:

1. Чистий операційний грошовий потік (Net Operating Cash Flow) за рік t (t \ge 1): \text{Net Operating Cash Flow}(t) = R_{\text{oil}}(t) + C_{\text{storage}}(t) - C_{\text{purch}}(t) - C_{\text{rec}}(t) - \text{OPEX}(t) де R_{\text{oil}} — виручка від реалізації нафти, C_{\text{storage}} — кредит/дохід від захоронення CO₂, C_{\text{purch}} — витрати на закупівлю свіжого CO₂, C_{\text{rec}} — витрати на компресію та рециркуляцію видобутого CO₂, \text{OPEX} — операційні витрати родовища.
2. Коефіцієнт дисконтування за середину року (Mid-Year Convention Discount Factor): DF(t) = (1 + r)^{-(t - 0.5)} де r — річна ставка дисконтування (наприклад, r = 0.10 для 10% дисконтування).
3. Накопичений дисконтований грошовий потік (Cumulative NPV): \text{Cum NPV} = -\text{CAPEX} + \sum_{t=1}^{T} \left( \text{Net Operating Cash Flow}(t) \times DF(t) \right) Застосовується непорушне правило: Повний динамічний CAPEX зараховується у рік 0 (t=0) без дисконтування. Дисконтування операційних грошових потоків починається з 1-го року із застосуванням коефіцієнта DF(t).

Нумеровані критерії приймання уніфікації розрахунку NPV (Acceptance Criteria):

1. Єдина обчислювальна траєкторія: Шляхи розрахунку NPV у модулі сурогатного рушія (surrogate_engine.py), аналітичних моделях (surrogate_models.py) та модулі експорту (run_exporter.py) повністю уніфіковані. Спрощений метод усереднення грошових потоків (типу N_p / 15) суворо заборонений.
2. Абсолютна точність збігу (0.00 Discrepancy):**Показник `economic_npv_usd` у файлі маніфесту (Manifest), значення `results["npv"]` у розрахунковому рушії (Engine) та підсумковий рядок `Cumulative_NPV_USD` у підсумковій таблиці грошових потоків (`cash_flows_yearly.csv`) повинні збігатися з точністю до**0.01.
3. Повне вилучення евристичних штрафів: Повністю вилучено нефізичні множники та алгоритмічні штрафні бар'єри (такі як result *= breakthrough_impact або штрафи -1.0 \times 10^{12}). Динаміка прориву газу регулюється виключно зростанням операційних витрат на рециркуляцію та компресію у моделі DCF.
