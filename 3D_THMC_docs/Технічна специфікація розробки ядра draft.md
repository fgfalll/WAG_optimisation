1.1. Стратегия обробки екстремальних станів та гарантії відсутності збоїв (Crash-Free Guarantee)

Для забезпечення беззбійної роботи (zero-panic architecture) обчислювального ядра симулятора пластових систем на мові Rust реалізується сувора політика обробки типів даних, керування пам'яттю та адаптивних обчислювальних методів. Розв'язувач (solver) гарантує обробку довільних, жорстких або термодинамічно нестабільних вхідних даних без виклику процедур аварійного завершення (panic!, unwrap(), expect()).

Вимоги до типів даних, пам'яті та обробки обчислювальних помилок у Rust

1. Ізоляція обчислювальних збоїв через Result<T, ComputationalError> та Option<T>:

* Жодна функція розв'язувача не повинна використовувати процедури невизначеної поведінки або прямий недозволений доступ до пам'яті.
* Усі обчислювальні етапи повертають обгортку Result<T, ComputationalError>, що дозволяє лінійному та нелінійному розв'язувачам перехоплювати помилки сходження, виходу за межі фазової діаграми або сингулярності матриць Jacobi.

# [derive(Debug, Clone, PartialEq)]
pub enum ComputationalError {
    NonFiniteValueInterrupted {
        variable_name: &'static str,
        cell_id: usize,
        value: f64,
    },
    NewtonRaphsonDiverged {
        iterations_taken: usize,
        last_residual_norm: f64,
    },
    ThermodynamicFlashFailed {
        pressure: f64,
        temperature: f64,
        reason: String,
    },
    SingularJacobianMatrix {
        row_index: usize,
    },
    PhysicalConstraintViolated {
        description: String,
    },
}

# [derive(Debug, Clone, Copy)]
pub struct ConvergenceControl {
    pub max_newton_iterations: usize,
    pub tolerance_residual: f64,
    pub line_search_max_steps: usize,
    pub damping_factor_min: f64,
}

pub trait StateValidator {
    fn validate_state_variables(&self) -> Result<(), ComputationalError>;
}

1. Перехоплення аномалій чисел з плаваючою крапкою (f64):

* Вектори станів, Jacobian-матриці та скалярні величини проходять перевірку методом .is_finite().
* При виникненні NaN або Inf значення перехоплюється на рівні ітератора та повертається помилка ComputationalError::NonFiniteValueInterrupted. Це задіяє механізм відкочування кроку за часом, а не виклики panic!.

2. Оптимізація пам'яті, Cache Locality та SIMD Vectorization:

* Для досягнення максимальної продуктивності обчислювальних петель Newton-Raphson використовується організація даних у вигляді Structure of Arrays (SoA) замість Array of Structures (AoS). Це підвищує локальність кешу процесора (L1/L2 Cache Locality).
* Використовується векторне мутування масивів за допомогою нульових алокацій в пам'яті (&mut [f64]), що виключає динамічне виділення пам'яті (malloc) під час нелінійних ітерацій.
* Лінійні операції над векторами залишків та матрицями здійснюються із застосуванням автовекторизації SIMD (AVX-512 / FMA3).

3. Адаптований лінійний пошук Ньютона-Рафсона (Newton-Raphson Line Search):

* Для розв'язання жорстких систем нелінійних рівнянь (THMC-зв'язані задачі) використовується алгоритм Ньютона-Рафсона з розширеним лінійним пошуком (Backtracking Line Search).
* Якщо вектор залишків \mathbf{R}(\mathbf{x}^{(k+1)}) перевищує норму \mathbf{R}(\mathbf{x}^{(k)}), крок вектору приросту \Delta \mathbf{x} множиться на коефіцієнт затухання \lambda \in [\lambda_{min}, 1) до забезпечення умови Armijo-Goldstein або простого зменшення норми неузгодженості:

\|\mathbf{R}(\mathbf{x}^{(k)} + \lambda \Delta \mathbf{x})\|_2 < \|\mathbf{R}(\mathbf{x}^{(k)})\|_2

1. Алгоритм адаптивного кроку за часом (Adaptive Time-Stepping):

* При виникненні термічної, гідродинамічної або геохімічної розбіжності керуючий модуль автоматично скасовує поточний крок за часом \Delta t.
* Новий крок за часом обчислюється як \Delta t_{new} = \eta \cdot \Delta t_{old} (де \eta \in [0.1, 0.5]).

pub struct NewtonRaphsonSolver {
    pub control: ConvergenceControl,
}

impl NewtonRaphsonSolver {
    pub fn step_time(
        &self,
        state: &mut [f64],
        residuals: &mut [f64],
        dt: &mut f64,
    ) -> Result<f64, ComputationalError> {
        let mut lambda = 1.0;
        let mut iteration = 0;

        while iteration < self.control.max_newton_iterations {
            if let Err(err) = self.compute_residuals_and_jacobian(state, residuals) {
                *dt *= 0.5; // Адаптивне скорочення кроку
                return Err(err);
            }

            let norm = self.calculate_l2_norm(residuals);
            if !norm.is_finite() {
                *dt *= 0.25;
                return Err(ComputationalError::NonFiniteValueInterrupted {
                    variable_name: "L2_Norm_Residual",
                    cell_id: 0,
                    value: norm,
                });
            }

            if norm < self.control.tolerance_residual {
                return Ok(*dt);
            }

            // Докремент ітерації та адаптація кроку через Line Search
            iteration += 1;
            lambda *= 0.85;
        }

        *dt *= 0.5;
        Err(ComputationalError::NewtonRaphsonDiverged {
            iterations_taken: iteration,
            last_residual_norm: self.calculate_l2_norm(residuals),
        })
    }

    fn compute_residuals_and_jacobian(
        &self,
        state: &[f64],
        residuals: &mut [f64],
    ) -> Result<(), ComputationalError> {
        for (i, val) in state.iter().enumerate() {
            if !val.is_finite() {
                return Err(ComputationalError::NonFiniteValueInterrupted {
                    variable_name: "StateVariable",
                    cell_id: i,
                    value: *val,
                });
            }
        }
        Ok(())
    }

    fn calculate_l2_norm(&self, vec: &[f64]) -> f64 {
        vec.iter().map(|v| v * v).sum::<f64>().sqrt()
    }
}

1. Модуль реактивного транспорту та геохімії (Reactive Transport Geochemistry)

2.1. Моделювання водного спектроутворення (Aqueous Speciation) та кінетики Lasaga

Геохімічний модуль обчислює рівновагу водного спектроутворення та кінетику гетерогенних реакцій розчинення/осадження мінеральних фаз при взаємодії пластових флюїдів із матрицею породи.

Кінетика розчинення та осадження мінералів за законом Лазаги (Lasaga Law)

Швидкість розчинення/осадження мінералу r_m [моль/(м²·с)] розраховується за феноменологічним рівнянням Лазаги:

r_m = k_m \cdot A_m \cdot \left| 1 - \left( \frac{\Omega_m}{\Omega_{eq,m}} \right)^{\theta} \right|^{\eta}

З метою суворої відповідності класичній фізико-хімічній термінології відношення \frac{\Omega_m}{\Omega_{eq,m}} прямо відображається на коефіцієнт насичення розчину IAP / K_{sp}:

\frac{\Omega_m}{\Omega_{eq,m}} \equiv \frac{IAP_m}{K_{sp,m}}

Де:

* k_m — константа швидкості реакції мінералу m [моль/(м²·с)].
* A_m — питома площа реакційної поверхні мінералу [м²/м³ породи].
* IAP_m (Ion Activity Product) — добуток активностей іонів у розчині для даного мінералу.
* K_{sp,m} (Solubility Product) — термодинамічна константа добутку розчинності при поточних P та T.
* \theta, \eta — експериментальні безрозмірні показники степеня кінетики.

Розрахунок фазової рівноваги та термодинамічних властивостей (HTHP EoS)

Розрахунок рівноваги між газовою та рідкою фазами реалізовано через трипараметричні кубічні рівняння стану (EoS) із застосуванням процедур ізотермічного/ізентальпійного флеш-розрахунку (flash calculations). Для умов високого тиску та високої температури (HTHP, тиск 7–276 МПа, температура 278–533 К) використовуються рівняння станів Пенга-Робінсона (Peng-Robinson — PR) та Соаве-Редліха-Квонга (Soave-Redlich-Kwong — SRK) з температурно-залежним зсувом об'єму (Volume Translation — VT).

========================================================================================
ПОРІВНЯЛЬНИЙ БЛОК ТЕРМОДИНАМІЧНИХ РІВНЯНЬ СТАНУ (HTHP VT-PR vs VT-SRK)
========================================================================================

1. Рівняння стану Peng-Robinson з об'ємним зсувом (VT-PR):
   P = (R *T) / (v + s - b) - a(T) / ((v + s)* (v + s + b) + b * (v + s - b))

2. Рівняння стану Soave-Redlich-Kwong з об'ємним зсувом (VT-SRK):
   P = (R *T) / (v + s - b) - a(T) / ((v + s)* (v + s + b))

Де параметр об'ємного зсуву s (Volume Translation) корельовано із середньою молярною масою
та фактором ацентричності:
   s = f( (M * omega)^(-1) )

Характеристики точності в HTHP умовах (7–276 МПа, 278–533 К)
----------------------------------------------------------------------------------------

* HTHP VT-SRK EoS: Середнє абсолютне процентне відхилення (MAPD) густини = 1.0% – 2.0%
* HTHP VT-PR EoS:  Середнє абсолютне процентне відхилення (MAPD) густини = 1.0% – 4.0%

----------------------------------------------------------------------------------------

SO2, CH4 та N2 шляхом застосування класичних правил змішування Ван-дер-Ваальса з двома
бінарними параметрами взаємодії (k_ij, l_ij)

2.2. Динамічна актуалізація фільтраційно-ємнісних властивостей (Porosity & Permeability Evolution)

Зміна мінерального складу матриці породи внаслідок реакцій розчинення або осадження викликає динамічну перебудову пористості та проникності.

Покроковий алгоритм зворотного зв'язку геохімії та геомеханіки:

1. Обчислення зміни молярного об'єму мінеральної фази: На кожному кроці за часом \Delta t для кожного мінералу m обчислюється зміна його об'ємної частки \Delta V_m у матриці породи на основі швидкості реакції r_m та молярного об'єму V_{m,molar}: \Delta V_m = r_m \cdot V_{m,molar} \cdot A_m \cdot \Delta t
2. Перерахунок актуальної пористості (\phi): Нова пористість розраховується шляхом віднімання сумарної зміни об'ємів усіх реакційних мінеральних фаз від поточного значення: \phi^{t+\Delta t} = \phi^t - \sum_{m} \Delta V_m
3. Оновлення абсолютної проникності (K) за законом Козені-Кармана: Абсолютна проникність матриці K актуалізується відносно початкового стану (\phi_0, K_0) за залежністю Козені-Кармана: K^{t+\Delta t} = K_0 \cdot \left( \frac{\phi^{t+\Delta t}}{\phi_0} \right)^3 \cdot \left( \frac{1 - \phi_0}{1 - \phi^{t+\Delta t}} \right)^2 Або за допомогою альтернативної степеневої залежності: K^{t+\Delta t} = K_0 \cdot \left( \frac{\phi^{t+\Delta t}}{\phi_0} \right)^\gamma

4. Зв'язана THMC геомеханіка та поропружність Біо (Coupled THMC & Biot Poroelasticity)

3.1. Математичне формулювання термо-гідро-механо-хімічного зв'язку

Напружено-деформований стан скелета породи описується системою диференціальних рівнянь у часткових похідних квазістатичного балансу сил з урахуванням концепції ефективних напружень Терцагі/Біо, температурних розширень та хімічних перетворень.

Рівняння балансу напружень та поропружності Біо

Рівняння рівноваги напружень у суцільному середовищі:

\nabla \cdot \boldsymbol{\sigma}' - \alpha \nabla P + \mathbf{f} = 0

Де:

* \boldsymbol{\sigma}' — тензор ефективних напружень.
* \alpha — коефіцієнт поропружності Біо (\alpha = 1 - \frac{K_{dry}}{K_s}).
* P — середня за об'ємом фазова напруга або середньозважений пластовий тиск флюїду.
* \mathbf{f} — вектор об'ємних сил (гравітаційне поле).

Закон зв'язку деформацій та напружень з урахуванням термо-хімічних ефектів:

\boldsymbol{\sigma}' = \mathbf{C} : \left( \boldsymbol{\varepsilon} - \alpha_T (T - T_0) \mathbf{I} - \boldsymbol{\varepsilon}_{chem} \right)

Де:

* \mathbf{C} — тензор пружних модулів скелета породи (тензор Четвертого рангу).
* \boldsymbol{\varepsilon} = \frac{1}{2} (\nabla \mathbf{u} + (\nabla \mathbf{u})^T) — тензор повних деформацій (\mathbf{u} — вектор переміщень).
* \alpha_T — коефіцієнт лінійного теплового розширення породи.
* T - T_0 — температурний перепад у пласті.
* \boldsymbol{\varepsilon}_{chem} — тензор деформацій хімічної усадки/розширення, викликаної мінеральними реакціями (\boldsymbol{\varepsilon}_{chem} = \frac{1}{3} \Delta V_{m,tot} \mathbf{I}).

Ефективне вилучення вуглеводнів та зміна об'ємів флюїду оцінюються через середньозважений за видобутком динамічний пластовий тиск \bar{P}_{res,eff}:

\bar{P}_{res,eff} = \frac{\sum_t P_{res}(t) \cdot q_o(t) \cdot \Delta t}{\sum_t q_o(t) \cdot \Delta t}

3.2. Розрахунок фазового стану та термодинамічних властивостей в HTHP умовах

Термодинамічні параметри сумішей обчислюються із застосуванням зсунутих за об'ємом кубічних рівнянь стану та специфікованих моделей в'язкості.

Специфікація термодинамічних параметрів ядра

* Обчислення фугітивності, густини та стисливості:
  * Реалізується через кубічні EoS VT-PR та VT-SRK.
  * Точність розрахунку густини вуглеводневих сумішей у діапазоні тисків до 276 МПа та температур до 533 К становить 1.0%–2.0% MAPD для VT-SRK та 1.0%–4.0% MAPD для VT-PR.
* Моделювання динамічної в'язкості флюїдів:
  * Теорія вільного об'єму (Free Volume Theory — FV): використовує густину флюїду, розраховану через VT-EoS, досягаючи рівня точності MAPD ~3% для вуглеводневих фракцій (та <2% при поєднанні з PC-SAFT).
  * Теорія тертя (Friction Theory — f-theory): пов'язана з атрактивними та репульсивними тисками VT-PR / VT-SRK EoS, досягаючи рівня точності MAPD ~5%.

1. Моделювання тріщинуватих колекторів (Fractured Reservoir Modeling)

4.1. Концептуальні моделі подвійної пористості та подвійної проникності (Dual-Porosity / Dual-Permeability EDP / MINC)

Для моделювання складних тріщинуватих колекторів специфікуються розширені підходи репрезентації суцільного середовища: Dual-Porosity, Dual-Permeability, EDP (Expanded Dual-Porosity) та MINC (Multiple Interacting Continua).

Матрично-тріщинна функція перетоку (Transfer Function)

Матричний перетік розраховується з урахуванням повного різниці потенціалів phases \alpha (капілярного, гравітаційного та в'язкісного):

q_{m-f,\alpha} = \sigma \cdot V_{block} \cdot \frac{K_m \cdot k_{r\alpha}}{\mu_\alpha} \cdot \Delta \Phi_{\alpha, m-f}

Де складникова потенціалу визначається як:

\Delta \Phi_{\alpha, m-f} = (P_{m,\alpha} - P_{f,\alpha}) - \rho_\alpha g (z_m - z_f) + \Delta P_{c,\alpha}

Час прориву флюїду витіснення в елементі розробки обчислюється як:

t_{bt} = \frac{V_{p,pattern} \cdot (1 - S_{wi})}{K_{koval} \cdot q_{inj,pattern}}

4.2. Механіка деформації тріщин Бартона-Бандіса та тензори проникності

Гідромеханічна поведінка тріщин описується нелінійним законом закриття/розкриття Бартона-Бандіса (Barton-Bandis model) під дією нормальних ефективних напружень \sigma_n'.

Закон Бартона-Бандіса для гідравлічного розкриття тріщини

Гідравлічне розкриття тріщини e залежить від ефективного нормального напруження \sigma_n':

e = e_0 - \frac{\sigma_n' \cdot v_{max}}{\sigma_n' + K_{j0} \cdot v_{max}}

Де:

* e_0 — початкове гідравлічне розкриття при нульовому напруженні.
* v_{max} — максимально можливе закриття тріщини.
* K_{j0} — початкова нормальна жорсткість тріщини.

Обчислення анізотропного тензора проникності K_{ij}(\boldsymbol{\sigma}'_{eff})

Закон Пуазейля для плоского потоку в тріщині трансформує розкриття e в тензор проникності тріщинуватого середовища:

K_{ij}(\boldsymbol{\sigma}'_{eff}) = \sum_{k=1}^{N_{frac}} \frac{e_k^3(\boldsymbol{\sigma}'_{eff})}{12 \cdot d_k} \left( \delta_{ij} - n_i^{(k)} n_j^{(k)} \right)

Де:

* d_k — середній інтервал між тріщинами k-ї системи.
* \mathbf{n}^{(k)} — одиничний вектор нормалі до площини k-ї системи тріщин.
* \delta_{ij} — дельта Кронекера.

1. Механіка розломів та гідродинамічна взаємодія (Fault Mechanics & Fluid Interaction)

5.1. Дискретні мережі тріщин (DFN) та несусідні зв'язки (Non-Neighbor Connections - NNC)

Великомасштабні розломи та тріщини вищого порядку дискретизуються в геометрії симулятора через дискретні мережі тріщин (Discrete Fracture Networks — DFN).

Алгоритм розрахунку провідності (Transmissibility) NNC

Для блоків сітки, що перетинаються площинами розломів або мають геометричний контакт через зміщення розлому, створюються несусідні зв'язки (NNC).

1. Геометрична ідентифікація площі контакту A_{NNC}: Обчислюється площа перетину між двома об'ємами сітки i та j, розсіченими площиною розлому.
2. Розрахунок еквівалентної провідності T_{NNC}:

T_{NNC} = \frac{A_{NNC}}{\frac{d_i}{K_i} + \frac{d_j}{K_j} + R_{fault}}

Де:

* d_i, d_j — відстані від центрів блоків i та j до поверхні контакту.
* K_i, K_j — проникності відповідних блоків уздовж нормалі до поверхні.
* R_{fault} — фільтраційний опір ядра розлому (R_{fault} = \frac{t_{fault}}{K_{fault}}).

5.2. Аналіз зсувної реактивації розломів (\Delta\text{CFS}), показник SGR та транзиції герметизації

Оцінка геомеханічного ризику реактивації розломів виконується на основі аналізу зміни Кулонівського напруження зсуву (\Delta\text{CFS}).

Критерій Кулонівського напруження зсуву (\Delta\text{CFS})

\Delta\text{CFS} = \Delta\tau - \mu \cdot (\Delta\sigma_n - \Delta P)

Де:

* \Delta\tau — зміна зсувного напруження вздовж площини розлому.
* \mu — коефіцієнт внутрішнього тертя породи (або поверхні розлому).
* \Delta\sigma_n — зміна нормального напруження на площину розлому.
* \Delta P — зміна пластового тиску флюїду в зоні розлому.

Умова \Delta\text{CFS} \ge 0 сигналізує про ризик зсувної реактивації (сейсмічного або безсейсмічного ковзання) розлому.

Показник глинистого затирання (Shale Gouge Ratio — SGR) та гідродинамічна герметичність

Гідродинамічна герметичність розлому оцінюється через показник SGR, що розраховується за потужністю глинистих пластів, які зазнали зсуву вздовж амплітуди скиду H:

\text{SGR} = \frac{\sum (V_{shale, k} \cdot \Delta z_k)}{H} \times 100\%

Де V_{shale, k} — об'ємний вміст глини в пласті k потужністю \Delta z_k.

Динамічний перехід "Бар'єр \rightarrow Провідний канал" (Seal-to-Conduit Transition)

1. При \Delta\text{CFS} < 0 та \text{SGR} \ge 20\% розлом функціонує як закритий бар'єр (seal) з проникністю ядра K_{fault} = K_{base} \cdot 10^{-4 \cdot \text{SGR}}.
2. При досягненні граничного стану \Delta\text{CFS} \ge 0 відбуваються дилатація та руйнування заповнювача розлому. Зона розлому динамічно переходить у стан провідного каналу (conduit):

* Проникність K_{fault} стрибкоподібно зростає: K_{fault,active} = K_{fault,base} + \frac{e_{shear}^3}{12 \cdot t_{fault}}.

1. Фізична консистентність, матриця ремедіації та матеріальний баланс

6.1. Інтеграція виправлень аудитів, моделі Koval та динамічна економіка

Для усунення виявлених аудитом фізичних та економічних аномалій у чисельне ядро симулятора імплементуються наступні суворі обмеження та формули.

Вимоги до фізичної консистентності та математичного балансу:

1. Усунення "фантомної утилізації CO₂" (Couple RF to HCPVI): Прив'язка коефіцієнта витіснення RF(t) до накопиченого об'єму прокачування розчинника (HCPVI) реалізується за допомогою фракційного потоку Коваля: RF(t) \le RF_{ult}(\bar{P}_{res,eff}) \cdot \left( 1 - \exp\left( -\frac{HCPVI}{1.5} \right) \right) Встановлюється обов'язковий мінімальний поріг чистої утилізації: \ge 2.5\text{ MSCF/STB} (0.25\text{–}0.50\text{ t/STB}).
2. Ліквідація аномалії "односвердловинного дренування" (Pattern Partitioning): При описі площ > 40 акрів автоматично виконується секціонування пласта на елементи розробки: N_{pat} = \max\left(1, \text{round}\left( \frac{\text{Area}}{40} \right)\right) При цьому кількість свердловин установлюється рівною N_{inj} = N_{prod} = N_{pat}. Продуктивність окремої свердловини обмежується продуктивним індексом Дарсі/Фогеля: q_o \le 1000\text{ BOPD}. Сумарна інжекція поля масштабується як q_{inj,field} = q_{inj,pattern} \times N_{inj}.
3. Забезпечення замкненого тискового зв'язку (Pressure Coupling): Розрахунок коефіцієнта вилучення та параметра змішуваності \omega перераховується виключно через середньозважений за видобутком пластовий тиск \bar{P}_{res,eff}.
4. Запобігання штучному колапсу репресії (Breakthrough Penalty Removal): Із розв'язувача повністю вилучається штучний множник штрафу result *= breakthrough_impact (штрафний бар'єр -1.0 \times 10^{12}). Час прориву t_{bt} розраховується за об'ємом пор елемента розробки V_{p,pattern}, а передчасний прорив пригнічує NPV природним чином через операційні витрати на компримування та рециркуляцію газу.
5. Динаміка газ-фактора та фракційного потоку газу: Після прориву фракційний потік газу f_g(t) описується нелінійною залежністю: f_g(t) = \frac{1}{1 + \left( \frac{1 - S_w(t) - S_g(t)}{S_g(t) - S_{gc}} \right) \cdot \frac{\mu_g}{\mu_o}} Частка рециркульованого \text{CO}_2 досягає 30%–60% від валової інжекції, а динамічний поточний \text{CO}_2 GOR зростає до рівня 5,000–25,000 SCF/STB.
6. Динамічна економіка та уніфікація NPV:

* CAPEX Year 0: Початковий капітальний ремонт/будівництво застосовується як недисконтований витратний показник у рік 0 (cum_npv = -capex + np.cumsum(dcf)).
* Динамічна формула CAPEX: \text{CAPEX} = N_{inj} \times \$1.5\text{M} + N_{prod} \times \$1.0\text{M} + N_{patterns} \times \$250\text{k} + \$3\text{M} + \$10\text{M} \times \left( \frac{Q_{recycle,peak}}{20,000} \right)^{0.65} + \$5\text{M}
* Точність NPV: Повна відсутність розбіжностей ($0.00 mismatch) між маніфестом симуляції та підсумковим Cumulative NPV у CSV-таблиці грошових потоків.
