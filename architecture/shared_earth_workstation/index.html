    Shared Earth Reservoir Workstation Architecture (v4.0)¶

    [!NOTE] This document is the definitive architectural specification for the Integrated Shared Earth Model, Subsurface Visualizers, and Multi-Domain Diagnostic Workstation in the CO₂ EOR Optimizer repository.

    1. Architectural Paradigm: The 5-Pillar Shared Earth Model¶

    In field-scale reservoir engineering and numerical simulation, the reservoir cannot be represented as isolated input textboxes. Modifying a parameter in one physical domain dynamically cascades through dependent physics across the model:

    ┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                   SHARED EARTH RESERVOIR MODEL                                   │
├──────────────────────────┬──────────────────────────┬────────────────────────────────────────────┤
│ Static Grid & Geology    │ Fluids & SCAL            │ Well Architecture                          │
│ • Corner-point / Unstruct│ • Peng-Robinson EOS      │ • 3D Trajectories & Completions            │
│ • Facies, φ, k_x,k_y,k_z │ • Stone I 3-Phase RelPerm│ • Peaceman Anisotropic Index (WI_horiz)    │
│ • Geostatistics (SGS)    │ • Carlson Gas Hysteresis │ • Vogel-Darcy IPR & Lift Curves (VFP)      │
├──────────────────────────┴──────────────────────────┴────────────────────────────────────────────┤
│ Geomechanics, Caprock & Fault Integrity                                                          │
│ • 3D Fault Surface Mesh & Throw Offsets (SGR) | Poroelastic Stress Paths (σ_h, α)                 │
│ • Thermo-Elastic Cooling (ΔT) & Coulomb Failure Stress (ΔCFS) | Capillary Entry Pressure (P_ce)  │
├──────────────────────────────────────────────────────────────────────────────────────────────────┤
│ Dynamic Flow Engine (Coupled 3D Surrogate Engine with Pseudo-Functions / Compositional Overlay)  │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘

    The 5 Coupled Pillars:¶

    1. Static Grid & Stratigraphy Framework:
    2. 3D grid container supporting structured IJK / corner-point grids initialized via Sequential Gaussian Simulation (SGS).
    3. Directional absolute permeabilities (\(k_x, k_y, k_z\)), porosity (\(\phi\)), Net-to-Gross (\(NTG\)), and structural dip (\(\theta_{dip}\)).
    4. Thickness-weighted average permeability: \(k_{avg} = \sum k_i h_i / \sum h_i\).
    5. Dykstra-Parsons heterogeneity index: \(V_{DP} = (k_{50} - k_{84.1}) / k_{50}\), calibrating Koval heterogeneity factor \(H_K = 10^{V_{DP} / (1 - V_{DP})}\).
    6. Fluid Thermodynamics & Multiphase SCAL:
    7. Multi-component Peng-Robinson EOS with volume translation and \(k_{ij}\) binary interaction parameter matrix.
    8. Rigorous 1D cell-to-cell slim-tube simulation solver determining dynamic Multiple-Contact Miscibility (MCM MMP) for impure gas streams (\(\text{N}_2, \text{CH}_4, \text{H}_2\text{S}\)) and heavy oils.
    9. Modified Stone I 3-phase relative permeability model: \(k_{ro} = \frac{S_o^*}{(1 - S_w^*)(1 - S_g^*)} \cdot k_{row}(S_w) \cdot k_{rog}(S_g)\).
    10. Carlson (1981) / Land (1968) trapped gas saturation hysteresis during WAG water cycles: \(S_{gt} = \frac{S_{gi}}{1 + C \cdot S_{gi}}\), where \(C = \frac{1}{S_{gr}^{\text{max}}} - \frac{1}{1 - S_{wc}}\).
    11. Well Architecture, Completions & Inflow Hydraulics:
    12. True 3D well trajectories: Vertical, Horizontal, Deviated S-Curve, and Fishbone Multilaterals.
    13. Peaceman (1983) anisotropic horizontal well index: \(WI_{horiz} = \frac{2\pi \sqrt{k_y k_z} \cdot L_{lat}}{\ln(r_{o,h} / r_w) + s}\).
    14. Composite Vogel-Darcy inflow performance relationship clamped to artificial lift capacity (\(\le 1,000\text{ BOPD}\)).
    15. Well-driven pattern assignment (Huff-n-Puff for 1 well; WAG, SWAG, Continuous for \(\ge 2\) wells with vertical completion overlap \(\Omega_{overlap} \ge 20\%\)).
    16. Geomechanics, Caprock & Fault Integrity:
    17. Near-wellbore thermo-poroelastic stress path accounting for cold \(\text{CO}_2\) injection: \(\Delta \sigma_h(t) = \gamma_h \Delta P(t) + \frac{E \alpha_{th}}{1 - \nu} \Delta T\) (\(\Delta T = T_{inj} - T_{res} < 0\)).
    18. Caprock capillary entry pressure sealing assessment: \(P_c = P_{\text{CO}_2} - P_w \ge P_{ce} = \frac{2 \gamma \cos \theta}{r_{throat}} \propto \sqrt{\frac{\phi_{cap}}{k_{cap}}}\).
    19. Dynamic fault slip reactivation via Coulomb Failure Stress Change: \(\Delta \text{CFS} = \Delta \tau - \mu_f (\Delta \sigma_n - \alpha \Delta P)\).
    20. Shale Gouge Ratio (Yielding & Bretan 1997): \(\text{SGR} = \frac{\sum (V_{shale} \Delta z)}{\text{Fault Throw}} \times 100\%\) (\(\ge 30\%\) sealing).
    21. Dynamic Flow Engine & Material Balance:
    22. Dynamic voidage replacement tracking: \(\text{VRR}(t) = \frac{B_w Q_{w,inj}(t) + B_{\text{CO}_2}(t) Q_{\text{CO}_2,inj}(t)}{B_o(t) Q_o(t) + B_w Q_w(t) + B_g(t) Q_{g,total}(t)}\).
    23. Dynamic tank material balance ODE updating pore pressure \(\bar{P}(t)\) and dynamic miscibility state \(M_f(t)\): \(\frac{d\bar{P}}{dt} = \frac{q_{inj,RB}(t) - q_{prod,RB}(t)}{V_p \cdot c_t + J_{eff} \cdot \Delta t}\).

    2. Centralized In-Memory State Manager (core/reservoir_state_manager.py)¶

    To eliminate parameter clobbering, race conditions, and synchronization lag, a unified state container is established:

    # Location: core/reservoir_state_manager.py
from PyQt6.QtCore import QObject, pyqtSignal

class ReservoirStateManager(QObject):
    """
    Centralized in-memory Shared Earth Model state container.
    Maintains dynamic coupling across Geology, PVT, Wells, Geomechanics, and Simulation.
    Emits granular Qt signals when any domain state changes.
    """
    state_modified = pyqtSignal(str) # Domain name
    geology_updated = pyqtSignal()
    pvt_updated = pyqtSignal()
    wells_updated = pyqtSignal()
    geomechanics_updated = pyqtSignal()
    simulation_ready = pyqtSignal(bool)

    Dynamic Coupling Invariants:¶

    1. Stratigraphy \(\to\) Deliverability: Changing layer thickness or permeability in the layer table immediately recalculates \(k_{avg}\), \(V_{DP}\), and all well indices (\(WI, J\)).
    2. PVT \(\to\) Containment & Recovery: Changing fluid composition or API immediately re-evaluates PR-EOS flash, updates \(P_{MMP}\), recalculates fluid densities (\(\Delta \rho\)), and updates caprock capillary buoyant pressure (\(\Delta P_{buoyancy}\)).
    3. Wells \(\to\) Pattern Conformance: Moving a well in 3D space immediately recomputes inter-well transmissibility \(T_{ij}\), vertical perforation overlap \(\Omega_{overlap}\), and updates the well pattern scheme.
    4. Injection Pressure \(\to\) Geomechanics: Changing injection rate or target bottomhole pressure immediately recalculates sandface thermo-poroelastic stress (\(\sigma_h(t)\)), Coulomb stress change (\(\Delta \text{CFS}\)), and the Mohr-Coulomb failure metric (\(F\)-value).

    4. Subsurface Visualizers & Pre-Flight Confirmation Framework (Workstream 1.4)¶

    1. GeostatisticsVisualizerWidget (ui/widgets/geostatistics_visualizer_widget.py):
    2. 1D Semi-Variogram Fit Canvas: Plots experimental spatial covariance lags (\(\gamma(h)\)) against theoretical Spherical, Exponential, and Gaussian curves with real-time sliders for Nugget (\(c_0\)), Sill (\(c\)), and Range (\(a\)).
    3. Fast 2D/3D SGS Realization Previewer: Calls core/geology/geostatistical_modeling.py (GSTools) to generate a \(50 \times 50 \times 10\) raster grid in \(<200\text{ ms}\), rendering permeability/porosity heatmaps and histograms.
    4. GeologyCrossSectionWidget (ui/widgets/geology_cross_section_widget.py):
    5. Interactive IJK Slicing: Orthogonal cross-section canvas (\(X\)-\(Z, Y\)-\(Z, X\)-\(Y\)) with sliders confirming structural dip (\(\theta_{dip}\)), layer thickness variations, and \(k_z / k_h\) anisotropy.
    6. Vertical Proportion Curves (VPC): Displays the vertical probability distribution of permeable sand (\(k > 10\text{ mD}\)) vs. impermeable shale barriers across each stratigraphic layer.
    7. FaultGeometryVisualizerWidget (ui/widgets/fault_geometry_visualizer_widget.py):
    8. 3D Fault Plane Mesh: Renders 3D fault planes cutting through the reservoir bounding box, showing throw offset and layer juxtaposition.
    9. Shale Gouge Ratio (SGR) Surface Heatmap: Color-codes fault seal integrity (Red: SGR < 20% leaking conduit; Yellow: 20–30% transitional; Green: > 30% ductile shale smear seal).
    10. Well-Fault Trajectory Overlay: Displays 3D well trajectories alongside fault planes to verify wellbore-to-fault buffer distances and completion interval clearances.
    11. Unified Visual Data Confirmation Gate ("Shared Earth Check") (ui/dialogs/visual_audit_modal.py):
    12. Mandatory 3-tab visual confirmation modal before the engine executes base simulation or optimization:
      • Tab 1: Heterogeneity & Variograms
      • Tab 2: Stratigraphy & Completions
      • Tab 3: Geomechanics & Containment
    13. Clicking "Approve & Confirm Subsurface Model" verifies, locks inputs, and dispatches the payload to SurrogateEngineWrapper.

    5. Multi-Domain Diagnostic & Evaluation Workstation (Workstream 6)¶

    The ModelEvaluationDashboard (ui/widgets/model_evaluation_dashboard.py) provides an exhaustive post-setup diagnostic and surveillance suite organized into five specialized tabs:

    1. Tab 1: Static QC & Geostatistical Surveillance:
    2. Experimental vs Theoretical Semi-Variograms along major, minor, and vertical azimuths.
    3. Petrophysical CDF distributions and kernel density estimates for \(\phi, k_h, k_v / k_h\), and \(NTG\) per zone.
    4. Interactive 3D cross-sectional fence diagrams showing facies continuity and layer pinch-outs.
    5. Tab 2: SCAL, Phase Behavior & Miscibility Surveillance:
    6. Complete PR-EOS \(P\)-\(T\) Phase Envelopes (bubble/dew curves, cricondenbar, cricondentherm, critical point \((T_c, P_c)\)) overlaying current reservoir state \((T_{res}, P_{res})\).
    7. Slim-Tube Oil Recovery vs Pressure Break-Over Curve (\(1.2\text{ PVI}\)) determining dynamic MCM MMP.
    8. Stone I 3-Phase Rel-Perm Ternary Surfaces with Carlson scanning loops.
    9. Tab 3: Dynamic Production & Material Balance Surveillance:
    10. Rate Transient Analysis (RTA) Log-Log Bourdet Derivative Diagnostic (\(\Delta P / q\) vs \(t_{mb}\), \(d(\Delta P / q)/d\ln t_{mb}\)).
    11. Flow regime identification (linear, bilinear, radial, boundary-dominated).
    12. Loss-ratio decline diagnostics: \(D(t) = -\frac{1}{q}\frac{dq}{dt}\) and \(b(t) = \frac{d}{dt}(1/D(t))\).
    13. Volumetric Material Balance Error (\(\text{MBErr} \le 0.1\%\)) and Voidage Replacement Ratio (\(\text{VRR}(t)\)).
    14. Tab 4: Containment, Geomechanical Integrity & Risk Surveillance:
    15. Dynamic 3D Mohr-Coulomb failure circles evolution over project life.
    16. \(F\)-value metric tracking distance to failure envelope: \(F = \frac{\tau_{crit} - \tau_{max}}{\sigma_m' \sin \phi_f}\).
    17. Effective stress path trajectories: \(\sigma'_h(t), \sigma'_v(t)\) vs \(P_{pore}(t)\) with tensile breakdown and fault slip thresholds.
    18. 3D Fault Plane SGR and Coulomb Shear Failure (\(\Delta \text{CFS}\)) heatmaps.
    19. Tab 5: Pattern Sweep, Streamlines & Flooding Surveillance:
    20. 3D Streamline time-of-flight flow paths: \(\tau(\mathbf{x}) = \int \frac{\phi}{v(\mathbf{s})} ds\).
    21. Injector-Producer Allocation Factors (IPAF): \(f_{ij} = Q_{ij} / \sum Q\).
    22. Flooding Efficiency Quadrant Cross-Plots (Offset Oil Produced vs Fluid Injected) to identify channelized injectors.

    6. Rendering Implementation Architecture¶

    ┌──────────────────────────────────────────────────────────────────────────────────┐
│ RENDERING ARCHITECTURE FOR SUBSURFACE ELEMENTS                                   │
├────────────────────────────────────────┬─────────────────────────────────────────┤
│ 3D Elements (OpenGL Accelerated)       │ 2D Elements (Publication Quality)       │
│ • Streamlines (GLLinePlotItem)         │ • Semi-Variograms (Matplotlib Canvas)   │
│ • Fault Surfaces (GLMeshItem)          │ • IJK Slices & VPC (Matplotlib Canvas)  │
│ • Well Trajectories (GLLinePlotItem)   │ • RTA Log-Log Bourdet (Matplotlib)      │
│ • Primary Engine: pyqtgraph.opengl     │ • Rel-Perm & Phase Envelopes (Matplotlib│
│ • Fallback Engine: Matplotlib mplot3d  │ • Mohr-Coulomb Circles (Matplotlib)     │
└────────────────────────────────────────┴─────────────────────────────────────────┘
    1. 3D Elements (pyqtgraph.opengl):
    2. Container: GLViewWidget.
    3. Streamlines & Well Paths: GLLinePlotItem with coordinate arrays \((N, 3)\), batched for performance, with velocity floor \(v_{\min} = 10^{-8}\text{ m/d}\) to prevent stagnation singularities.
    4. Fault Surface Meshes: GLMeshItem with vertex colors mapped to Shale Gouge Ratio (SGR) values.
    5. Zero-Dependency Fallback: Matplotlib mplot3d (Axes3D) automatically used if OpenGL context is unavailable.
    6. 2D Elements (Matplotlib FigureCanvasQTAgg):
    7. High-precision, publication-quality 2D scientific plotting for variograms, VPC distributions, 3-phase ternary diagrams, RTA Bourdet derivatives with logarithmic L-spacing smoothing (\(L = 0.2-0.4\)), and Mohr-Coulomb failure circles.
