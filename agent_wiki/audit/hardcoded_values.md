## 1. Executive Summary

An AST traversal targeting binary operations, comparison expressions, and function calls across active scientific computing modules identified **1,965 non-trivial hardcoded numerical values**.

Every important value has been audited to determine its physical meaning, unit, configurability, and whether it has an established scientific origin or constitutes an uncalibrated constant.
