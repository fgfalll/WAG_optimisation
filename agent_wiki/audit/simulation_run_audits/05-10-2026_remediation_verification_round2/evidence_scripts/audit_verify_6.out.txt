==============================================================================
J. SATURATION CLOSURE BREAKDOWN (np.clip masking)
==============================================================================
   n=181  timesteps with So+Sw>1 : 49  (27.1%)
   max(So+Sw) = 1.042829  -> Sg forced to 0 by np.clip
   time vector: 181 steps; first/last So+Sw = 1.003850 / 0.785422

   WHY: vp_dynamic uses pv_ref = OOIP*Bo_mean/(1-Swi) which is the HCPV (hydrocarbon PV),
   while So is computed as remaining_oil*Bo / vp_dynamic. The water term uses
   pore_volume_rb*Swi + water_inj - water_prod, divided by the SAME vp_dynamic.
   But Swi was defined on the TOTAL pore volume, not the hydrocarbon pore volume:
   total PV = PV/(1-Swi), so PV*Swi != PV_hcpv*Swi. The two saturation bases are
   inconsistent by construction -> So+Sw>1 -> Sg silently zeroed.
   numeric: PV_total=1,600,000 rb ; PV_hcpv=1,200,000 rb
   So(0) expected = OOIP*Bo/PV_total = 0.7500  (code gives 0.7538)
   Sw(0) expected = PV_total*Swi/PV_total = 0.25  (code gives 0.2500)
   code recomputed Sw(0) = (PV_hcpv*Swi)/PV_hcpv = 0.25  -> both use PV_hcpv => sum = (1-0.25)*Bo/PV_hcpv
   So(0)+Sw(0) = 1.003850

   keys actually in returned profiles: ['co2_gas_profile', 'solution_gas_profile', 'gas_profile']
